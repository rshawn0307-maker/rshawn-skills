# 技巧线内容策略（tips-content-strategy，C1 字段职责表）

15 字段是帖子内容字段；审稿记录字段（draft_meta）另见 `references/shared-sourcing.md`，两者不混。模板段位映射（C2，23 段 4 图）Task3 定稿。

## 15 字段职责表

| 字段 | 内容职责 | 约束 |
|---|---|---|
| tip_title | 卡点钩子标题 | ≤20 字（含前缀）；候选痛点式/具体改法式/原栏目式"考官想听的：xxx"，卡点式优先；正文兑现标题 |
| card_point | 卡点诊断：适用题型+你卡在哪+为什么卡 | 含认知增量点；单段≤4 行 |
| fix_summary | 改法一句话：本期只教 X+题骨前提一句 | 边界声明保留防残缺骨架 |
| demo | 定调版示范主体：opening+1 对应 body 段 | 标注改法落点；优先引用题库定调版逐字稿，无匹配新写标"示范"+回核；段首自动 👍 |
| step1/step2/step3 | 改法拆解，从示范归纳 | 每步=判断/动作/检查；步数服从原方法（两点法 step3=应用/检查）；至少一个抽象要点展开为能直接问出口的问句 |
| case_normal | 普通答法同部位 | 定调版口径可信常见答法；段首自动 🙅‍♂️；不偷加题干事实 |
| contrast_note | 对照点评：普通 vs 示范 | 逐句锚定 case_normal 原话；区分"没有说明 X"与"说错了 X"；Markdown 引用块+浅灰底 |
| boundary_scope | 适用边界 | 适用/不适用 |
| boundary_misuse | 常见误用+纠正动作 | |
| boundary_evidence | 数据出处/权限安全提示 | 吸收教师注 |
| exercise | 迁移练习 | 新场景任务（正文没出现过），所需知识正文已讲清 |
| self_check | 自查判据 | 2-3 条自检要素含一个适用判断；与练习分离 |
| hashtags | 话题标签 | 5-8 个，固定 #公考面试 #结构化面试 #上岸 |

## 补充内容规范

- 一期一技巧：聚焦带边界声明，题骨前提保留一句。
- 单段≤4 行，行内≤30 字，短句 8-20 字为主。
- emoji 每段≤2，限调色板 ❗️🙅❌✅📌💡⏰🗣。
- 数字可核验或有出处，无出处统计不写，模糊归因不写。
- 模拟例子标"示范"，不冒充作者经历。
- 真实不确定保留条件词。
