# 定调版口径（shared-calibration）

两线定调版口径的唯一事实源。引用方：技巧线工作流步 2（写前读源）/ 步 3（demo 字段与示范回核）、shared-gates.md 步 7 ⑦（示范口径符合）、tips-content-strategy.md `demo` 字段、答题线逐字稿（阶段 2）。

| 项 | 契约 |
|---|---|
| 逐字稿字数 | 700–800 汉字（不含标点），硬边界 680–820，目标 210 秒（思考 30 秒另计，不报实测） |
| 8 字段结构 | opening（破题定调）+ point1_lead/body + point2_lead/body + point3_lead/body + closing（判据式 40–60 字 / 总结式 80–100 字轮换） |
| 破题定调三禁 | 不编题干外事件 / 不写场景故事开头 / 不先讲经历 |
| 套话限制 | 同句定调套话同批最多 2 篇 |
| 主体 | 三块封顶，按题型选 3 观点 / 时间线 / 多维分析 |
| 技巧线示范 | 引用此口径的 opening + 1 个对应 body 段，不整篇 |
| 答题线 | 整篇此口径（阶段 2） |
| 权威源 | 246 道模拟题已按此重写（2026-11-17）；引用不引归档旧版 |
