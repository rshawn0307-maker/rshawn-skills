# 答一道 VI — 版式契约（DESIGN.md）

> 本文件是 `scripts/render_answer_cards.py` 的**唯一视觉事实源**。引擎常量与本文冲突时，
> 以本文为准并同步改引擎；二者必须同表。任何「照着感觉调一下」都是 bug。

**这份契约针对 1080×1440 静态 PNG（PIL 直出），不是网页。** 所有 web-only 规则
（hover/focus 状态、响应式断点、`text-wrap: balance`、容器查询、暗色模式切换、
`prefers-reduced-motion`）在本产物上**不适用**，下文不再逐条重复。适用性换算基准：
1080px 卡在手机上显示约 390pt 宽，**缩放系数 0.36**；信息流缩略图 85–120px 宽，
**缩放系数 0.08–0.11**。

## 1. Visual Theme & Atmosphere

**一句话立场**：把考场答案摊在桌面上给你看——冷静、克制、像一份改过的卷子，不像一张海报。

- **温度**：中性偏暖。底色暖米白（不是纯白），墨色偏褐（不是纯黑），但**只用暖度这一个方向**，
  不引入黄铜/奶油/陶土等第二个暖调层次（那是 AI 味的来源，见 §9）。
- **材质**：纸张。无渐变、无阴影、无玻璃拟态、无贴图纹理。`阴影默认 0`——引擎里没有任何
  shadow 实现，这是设计决策不是缺失。
- **密度立场**：内容页密集（逐字稿一页可到 20 行），呼吸页稀疏（封面、收尾）。**密度差是
  编排手段**，但同帖信息量波动控制在 ±30% 以内（见 §5 翻页节奏）。
- **参考拆解（Keep / Change / Do-not-copy）**：

  | 参考 | Keep | Change | Do-not-copy |
  |---|---|---|---|
  | card-xiaohongshu | 1080×1440 竖卡、一卡一观点、首卡封面/末卡 CTA、手机上字号够大 | 它建议莫兰迪粉系＋圆润元素；本 VI 走暖米＋枣红，圆角收敛到两档 | 多强调色、装饰性插画、贴纸感元素 |
  | redesign-skill | Scan→Diagnose→Fix 三步、按维度审计不推倒重来 | —— | —— |
  | impeccable-design-polish | 后置打磨定位、少量决定性修复优于大面积装饰 churn | 它的六模式（Animate/Harden/Live）对静态 PNG 无对象 | web 交互态打磨 |
  | taste-skill | 先写 Design Read 再动手、Anti-Default Discipline | —— | 它的「含糊时只问一个问题」——本产线有固定输入字段，不需要问 |
  | open-design-clean | 少色板、大留白、字距行高可读性优先 | 它是 web token 包（#3B82F6 等）；本 VI 只借它的结构，token 全部替换 | 蓝紫主色、8pt 通用栅格直接套用 |

- **v1 → v3 的三处决定性修复**（不是装饰 churn）：
  1. **正文 36px → 44px**：36px 在手机上等值 13px，长段落读不动。代价是 772 字必须从 2 页
     拆成 3 页（卡片数 6 → 7），这个取舍优先于「保持 6 卡」。
  2. **金棕 tabline + 页脚横线退役**：装饰条在 3 页以上重复＝AI 指纹；页脚加横线等于给
     页脚加权。二者删除后，强调只由「枣红色块 + 字号跳档」承担。
  3. **封面从满宽色块改左对齐贴字块**：满宽 banner 是默认 AI 居中块，且面积 14% 超上限。

## 2. Color

Engine 常量见 `render_answer_cards.py` 顶部色板区。

| 角色 | 常量 | Hex | 用途 | 对比度（on BG） |
|---|---|---|---|---|
| 画布底 | `BG` | `#fff8ec` | 全部卡片背景 | — |
| 主文字 | `INK` | `#271e1b` | 正文、标题、金句 | **15.45:1** |
| 次级文字 | `INK2` | `#4a3c36` | 次段正文、破题理由、收尾话 | **9.99:1** |
| 三级文字 | `INK3` | `#8c7f76` | 页脚、页码、微标、字数时长 | 3.67:1（水印类） |
| 强调色 | `CRIMSON` | `#87110f` | 封面色块、破题句、编号方块、CTA、微标 | **9.39:1** |
| 强调色上的字 | `CREAM_W` | `#fff8ec` | 枣红块内文字（与 BG 同值，角色不同） | 9.39:1 |
| CTA 副行 | `HERO_SUB` | `#ecdcc4` | 枣红 CTA 条上的第二行 | 7.37:1（on CRIMSON） |
| 结构线 | `RULE` | `#e2d7c8` | 仅供结构分隔，**不作装饰** | 1.35:1 |

**强调色纪律（硬约束）**：

- **全帖唯一强调色 = `CRIMSON`**，跨 7 卡不变。不许出现第二个色相强调。
- **面积上限**：单卡 ≤8%；**封面色块 ≤12%**。两种口径都要记，别混用（会差 3 个百分点）：
  - **包围盒面积**（视觉重量，改版看这个）：封面 `881×197 / (1080×1440)` = **11.2%**；
    卡 07 CTA `912×120` = **7.1%**。
  - **枣红像素占比**（实测墨量，测试看这个）：封面 **8.47%**；02=2.00% / 03=0.67% / 04=0.74% /
    05=0.82% / 06=0.90% / 07=6.82%。色块内是米白字，所以像素占比恒低于包围盒。
  - 契约门限按**包围盒**判（封面 ≤12%、单卡 ≤8%）；回归测试按**像素**判（封面 8%–12%），
    两者是同一设计的不同度量，不冲突。
- **每卡 ≤3 处**：封面＝色块 1 处；02＝微标 + 短线 + 破题句（3 处，到顶）；03/04/05/06＝编号方块
  （n 个方块算 1 组，不逐个计）；07＝短线 + CTA（2 处）。
- **对比度硬门槛**：正文 ≥7:1（实得 15.45/9.99）；次级 ≥4.5:1（实得 9.99）；水印类 ≥3:1
  （实得 3.67）；≥88px 大字 ≥3:1。
- **灰阶禁区**：`min(INK)` 必须落在 8–22 区间，`max(BG)` 必须 <255。当前 `min(INK)=27`、
  `max(BG)=255` —— **`BG` 的 255 通道是唯一已知越界项**，改版时若换底色，目标是把纯 255
  降下来（如 `#f7f5f1`）；本版保留 `#fff8ec` 以维持品牌连续性，作为 §9 已知例外登记。

**禁用色值（出现即 fail）**：

- 紫蓝色相 240–280°（`#8B5CF6` / `#6366F1` / `#3B82F6` 一类），AI 生成默认色。
- 黄铜/陶土 + 暖米底 + espresso 深墨三元组合（如 `#b08947` / `#9a2436` 配 `#f5f1ea` 底 +
  `#1a1714` 墨）——**第二常见 AI 指纹组合**，v1 的金棕 `#e3c79f` 正撞这条，已整体退役。
- 纯黑 `#000000` 作底或作正文；纯白 `#ffffff` 作底。
- 冷暖灰混用（同一产物里既有偏蓝灰又有偏暖灰）。

## 3. Typography

字体：**HarmonyOS Sans SC** 四档（Black / Bold / Medium / Regular），
`FONT_DIR = /Users/shawn/Library/Fonts`。缺任一档 → `ensure_assets()` 直接 STOP，不静默降级。

**六档字号梯**（`T_L0`…`T_L5`，全帖只许这六档，不得临时加第 7 档）：

| 档 | 常量 | size | 手机等值（×0.36） | 字重 | 行高 | 用途 |
|---|---|---|---|---|---|---|
| L0 | `T_L0` | 132（可降至 88） | 47.5pt | Black | `LH_COVER` 1.18 | 封面主标（主题） |
| L1 | `T_L1` | 84 | 30.2pt | Black | `LH_TITLE` 1.25 | 内页分节标题（如「核心观点」） |
| L2 | `T_L2` | 56 | 20.2pt | Bold / Medium | `LH_QUOTE` 1.45 | 题干、破题句、观点句、金句、封面副标 |
| L3 | `T_L3` | 44（可降至 42） | 15.8pt | Medium | `LH_BODY` 1.60 | 正文（逐字稿主体、观点正文） |
| L4 | `T_L4` | 35 | 12.6pt | Medium / Regular | `LH_NOTE` 1.55 | 次级正文、破题理由、收尾话 |
| L5 | `T_L5` | 28 | 10.1pt | Regular | `LH_MICRO` 1.30 | 页脚、页码、微标、字数时长、CTA 副行 |

**相邻档比**（必须落在 `[1.25, 1.6]`，`test case_scale_ladder` 断言）：
`132/84 = 1.571`、`84/56 = 1.500`、`56/44 = 1.273`、`44/35 = 1.257`、`35/28 = 1.250`。

> L4 取 **35** 而非常见的 36：`44/36 = 1.222` 会跌破 1.25 下限，而 `36/28 = 1.286` 偏松；
> 取 35 两个相邻比同时达标（1.257 / 1.250）。这不是凑数，是六档梯的整除约束结果。

**层级靠「字重 × 字号」交叉建立**，不靠字号单维：

| 组合 | 出现场景 |
|---|---|
| Black 132 + Medium 56 | 封面：主标 vs 副标 |
| Black 84 + Medium 35 | 内页标题 vs 导语 |
| Bold 56 + Medium 44 | 观点句 vs 正文（**同页最重要的对比**） |
| Medium 44 + Medium 35 | 正文 vs 次级正文（色阶同时从 INK 降到 INK2） |
| Bold 44 + Regular 28 | CTA 主行 vs 副行 |

实测「字重档 × 字号档」乘积 = 4 字重 × 6 字号 = **≥ 4**，通过反 AI 指纹 #1。

**行宽（硬约束）**：版心 `TX_W = 912px`，中文单字 advance == 字号，故：

- L3 44px → **20 汉字/行**（880px）；L4 35px → 26 字/行（超 24 上限，故 L4 只用于短段）；
  L2 56px → 16 字/行（低于 18 下限，故 L2 只用于题干/金句这类**短行**语体，不排长段）。
- 每行 18–24 汉字为达标区，硬上限 26；< 14 字视为碎裂。

**断行器**（`wrap_text_widths`）：PIL 没有 `text-wrap: balance`，全部自己实现。

1. 逐字累积测宽，超宽即断。
2. **避头**：`NO_LINE_START = "、，。：；！？·）》」』%,.;:!?)]"` 不落行首（断上一行末字）。
3. **避尾**：`NO_LINE_END = "「『（《"` 不落行尾（同上处理）。
4. **数字/英文串不腰斩**（`_is_ascii_alnum`）：`马上打119和120` 曾被折成「马上打11 / 9和120」，
   现整串随行迁移；`_balanced_lines` 的两行均衡同样跳过数字内部切点。
5. **末行孤字借字**：末行 1 字（或 2 字且含收尾标点）时从上一行借 1 字，且不借数字/英文。
6. **只折行，永不截断**——超高走降档（44→42），42 仍放不下即 `CardOverflow` → exit 非 0。
   **每张卡都必须有这道闸门**：卡 02 是固定字号（题干/破题句/理由不降档），所以它
   直接比 `total > ZONE_BOT - SCRIPT_ZONE_TOP` 后 `raise CardOverflow(2)`。
   历史教训 I-3：卡 02 曾用 `max(0, …)` 把超高静默钳住，超长题干 rc=0 出一张内容压到画外
   的图——闸门缺失比文字难看严重得多，因为它让「不许截断」这条铁律失去程序保障。

**标点与符号纪律**：

- 中点 `·` 每行 ≤1、全卡 ≤2（「每日一练 · 答一道」已是满额，别处不许再加）。
- 破折号 `—`/`–`/`——` **出现 1 次即 fail**（中文排版里它最像 AI 腔）。
- emoji：每卡 ≤2，只能出现在支撑条行首或标签位，**不许进封面主标**，全帖不重复，不作图标体系。
  当前产物 **0 个 emoji**（安全）。
- 英文外词全额小写或原样，不做 Title Case；中文标题不加装饰性空格。

## 4. Spacing & Grid

- **安全区**（按实测口径，勿按字面「四边 64px」理解）：`SAFE = 64` 约束的是**内容区**，
  即 `ZONE_TOP`–`ZONE_BOT` 之间的任何文字/色块不得越出左右 84px 版心。
  页眉 logo 与页脚文字是**既定例外**，实测值如下，改版不许随手挪动：
  - 左右：严格 84px（实测四边 64px 带内 left/right 非底色像素 = 0）
  - 上：页眉 logo 贴 `y = 28`（96px 封面 logo 贴 `y = 72`），比 64px 更靠上，属设计选择
  - 下：页脚文字 `y = 1372`，28px 字号使字形底伸到约 `y = 1400`，距画布底边仅 40px
  - 判定口径：**内容区越界 = fail；页眉页脚按上述既定值 = pass**。
    若两者冲突以本表为准，不要为了迁就 64px 而把页脚整体上提（会破坏跨卡锚点一致性）。
- **版心**：`MARGIN = 84`，`TX_X = 84`，`TX_W = 912`。左右留白 84px（手机等值 30pt）。
- **间距梯**（同组内距 / 异组间距，硬下限）：同组元素 ≥16px，异组 ≥32px。实装：
  `LEAD_BODY_GAP = 26`（观点句→正文，同组）、`PARA_BODY_GAP = 34`、`GROUP_GAP = 56`（组间）、
  `SQ_GAP = 20`（编号方块→文字）、`VIEW_GAP = 30`（观点之间）、`GOLDEN_CLOSING_GAP = 56`。
- **区域锚点**（跨卡同名锚点必须 ±2px 一致）：

  | 锚点 | 常量 | y 值 |
  |---|---|---|
  | 内页页眉 logo | `HEADER_LOGO_XY` | (84, 28)，尺寸 56 |
  | 内页字标基线 | `HEADER_TEXT_Y` | 56（anchor=lm） |
  | 封面 logo | `logo_cover` | (84, 72)，尺寸 96 |
  | 内容区上沿 | `SCRIPT_ZONE_TOP` | 176（逐字稿无 L1 标题时上探） |
  | 内容区下沿 | `ZONE_BOT` | 1290 |
  | 页脚文字 | `FOOTER_TEXT_Y` | 1372 |
  | 卡 06 字数时长 | `SCRIPT_NOTE_Y` | 1252 |
  | CTA 条 | `CTA_Y` + `CTA_H` | 1150 + 120 = 1270 |

- **垂直节奏**：单卡内所有行高由 `size × lh` 取整得出（`draw_lines` 的 `adv`），**同页一致**，
  不用「手动挪 y」调平衡。整组居中一律 `zone_top + (zone_h - group_h) // 2`。

| 结构短线 | `card2_question` / `card7_close` | 96×`RULE_W=3`，`CRIMSON`；只作结构分隔，全帖仅两处（02 题干与破题之间、07 金句上方） |
| 内页页眉 | `logo_header` | logo 56 圆角（r=0.22×56）贴 `(84,28)` + 字标 28 Bold `INK` anchor=lm 在 x=156 |
| 页脚 | `footer(d, idx)` | **无装饰横线**；左 `FOOTER_LEFT` 28 Regular `INK3`，右 `f"{idx:02d}/07"` 28 Regular `INK3`；对比 3.67:1（≤4.5 上限，不抢读） |
| 微标 | `micro_label` | 28 Regular `INK3` 默认，或 `CRIMSON`（如 02 的「每日一练」）；anchor 可 la/ra |
| CTA 条 | `card7_close` | 912×120，圆角 24，`CRIMSON`；主行 `CTA_MAIN` 44 Bold `CREAM_W` 在 `CTA_Y+42`；副行 `BRAND_SLOGAN` 28 Regular `HERO_SUB` 在 `CTA_Y+88` |
| 字数时长 | `script_badge` | `f"全文 {n} 字 · 约 {secs} 秒"`，28 Regular `INK3` 居中于 1252；`secs = round(n/3.5/10)*10` |

**形态锁**：圆角只用两档——`RADIUS_SMALL=12`（小元素，<64px 高）与 `RADIUS_LARGE=24`
（大块：封面色块、CTA）。**没有第三档**。最小线宽 `RULE_W=3`（1px 缩到手机是 0.36px，会消失）。
阴影：**全产物 0**。

## 8. Voice & Brand

- **人称**：正文第二人称（「你是政务服务大厅负责人」「你怎么办」）——题目语体决定，非营销语。
- **主张句 ≤30 汉字**；支撑条 ≤20 字；AI 陈词 **0 个**（赋能/闭环/抓手/颗粒度/打通/护城河
  一类一律不出现，由 `scripts/check_prose.py` 程序门禁兜底）。
- **品牌话术**：`BRAND_SLOGAN = "先答一道，把最影响得分的地方找出来"`（CTA 副行）；
  `COVER_SUB = "把最影响得分的地方找出来"`（封面副标，12 字，品牌话术截取，符合 ≤12 字上限）。
- **字标**：`WORDMARK = "结构化每日一练"`（内页页眉 28 Bold）。
- **页脚**：`FOOTER_LEFT = "结构化每日一练 · 答一道"`。
- **笔记文案**：由 final JSON 字段确定性拼装（`NOTE_TEMPLATE`），**不新增事实**；
  固定引导 `NOTE_GUIDE = "想要完整逐字稿，评论区打「1」"`；标签 `NOTE_TAGS` + `#题型`。

## 9. Anti-patterns & Known Exceptions

### 9.1 反向清单（命中即改）

| # | 反模式 | 本 VI 的判据 |
|---|---|---|
| A1 | 装饰条在 ≥3 页重复 | 内页 tabline / 页脚横线已全部删除；现存短线仅 02、07 两处 |
| A2 | 处处统一圆角 | 两档圆角 12/24，且按「小元素/大块」分级，不是全站一个值 |
| A3 | 页脚权重过高 | 页脚 28px、对比 3.67:1、无横条、无底色；底部 160px 墨量远低于 12% |
| A4 | 居中对称三段式 | 封面色块左对齐、内页全部左对齐；仅 07 金句居中（单句呼吸页，属刻意） |
| A5 | 只会尖叫的超大 H1 | 封面 `T_L0/T_L3 = 132/44 = 3.0`（≤4.0）；内页 `84/44 = 1.91`（≤3.0） |
| A6 | 一坨没有层级变化的正文 | 正文块内必有字号跳档（44→35）或色阶跳档（INK→INK2）作阅读锚 |
| A7 | 每页挂文案型 eyebrow | 只有 02「每日一练」一个微标 + 逐字稿页码「n/3」，其余页面无 |
| A8 | 中点 `·` 泛滥 | 每行 ≤1、全卡 ≤2 |
| A9 | 破折号 | 0 容忍 |
| A10 | 伪精确数字 / 占位名 / 无源引用 | 0 容忍；每卡至少 1 个可验证具体细节（如「119/120」「三本账」） |
| A11 | 多强调色 | 唯一 `CRIMSON`；`INK/INK2/INK3` 是灰阶不是强调 |
| A12 | 纯黑底 / 纯白底 | 底 `#fff8ec`、墨 `#271e1b`，均非极值（BG 的 255 见 9.3） |
| A13 | 紫蓝渐变 / glassmorphism / shadow | 全产物 0 |

### 9.2 已知例外（登记在案，不算 bug）

1. **L4 = 35px 而非 36px**：为使相邻档比全部 ≥1.25（见 §3）。36px 会让 44/36=1.222 越界。
2. **D 族（逐字稿）连续 3 页**：连续文本不宜插异版式；用「n/3」页码微标 + 卡 06 字数时长
   提供递进信号（见 §5）。
3. **卡 07 金句居中**：单句呼吸页，居中是对称特例；其余页面一律左对齐。
4. **L2 56px 行宽 16 字 < 18 下限**：L2 只用于题干/金句/观点句等短行语体，不排长段；
   长段一律 L3 44px（20 字/行）或 L4 35px。
5. **04/05/06 行数可到 20**（超出 T03 的 4–8 行）：它们是逐字稿长文族，行数由文本量决定，
   由 `CardOverflow` 与降档机制兜底，不做人为压缩。

### 9.3 未完全达标项（诚实登记）

- **`BG` 的 255 通道**：反 AI 指纹 #3 建议 `max(BG) < 255` 且底色偏 `#f7f5f1`/`#FAFAF9`。
  本版保留 `#fff8ec`（品牌连续性优先）。若下一版要收紧，改 `BG = (247, 245, 241)` 并同步
  重算 §2 全部对比度与 `test` 里的 `C5_BG` 断言。
- **`INK3` 对比 3.67:1**：作为水印类达标（≥3:1），但低于次级文字 4.5:1。页脚/页码属水印类，
  判定通过；**不可把 `INK3` 用于正文或需要精读的内容**。
