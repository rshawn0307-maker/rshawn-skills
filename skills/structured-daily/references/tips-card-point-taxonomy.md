Task7 填充完成。本文件是技巧线选题的卡点分类单一事实源：6 大类卡点定义与判定线索、标签词表（供 `tips_index.json` 每条 `card_points` 取值）、选题机制（含弹窗交互）、打标依据方法。索引 `_meta.card_point_taxonomy` 与本文件第 1-2 节内容一致。

## 1. 六大类卡点分类体系

六类是读者写答案时最常见的六种病根，由各题型方法论「常见误区」章、题库教师注与普通答法特征归纳而来（来源：`各题型方法论/*_方法论提炼.md` 七章、19 篇题库 src 教师注）。选题时按类诊断读者卡在哪，一期治一个主卡点。

### 1.1 破题空泛

- **定义**：开头停在现象表面、不敢下判断、或用万能套话起手，第一句没有把问题重新定义、没有方向性立场。
- **判定线索**（写稿选题时逐条对）：①第一句能不能给方向性判断或重新定义（如"根子不在应用多，在考核的尺子没换"）？②是不是"凡事预则立""领导把这项工作交给我"式万能开场？③争议题两面说完有没有收束到自己的判断，还是骑墙停住？
- **典型表现**：开口罗列现象清单不下结论；"既有利也有弊"收不了束；把结构问题归成情怀、态度等个人因素。
- **方法论对应**：综合分析误区「就事论事」「骑墙站队」、要点1「往深看一层」；人际方法论核心矛盾「万能模板」；自我认知误区「模板自我表扬」；言语误区「公文式演讲」。

### 1.2 结构散乱

- **定义**：答题没有排序意识——平均用力不分详略、轻重缓急颠倒、环节之间没有标注衔接，考官听不出层次。
- **判定线索**：①有没有排序句（"我判断第一位的是X，Y排在后面""这个顺序不能反"）？②详略有没有配比（重点给细节、其余一句带过）？③环节之间有没有标签句/过渡句让结构可辨？
- **典型表现**：五六件事每件说两三句；先追责再救人；现象、原因、对策混在一段里。
- **方法论对应**：应急误区「顺序混乱」「只处置不控场」；综分误区「分析扁平」；组织误区「模板套话（三段流水账）」。

### 1.3 内容空洞

- **定义**：观点落到口号层面不落地——对策只堆砌不给路径、动作没有主语/时间/工具、叙述缺数字场景细节撑不住追问。
- **判定线索**：①每条对策有没有"标题句+具体做法+预期效果"？②动作有没有主语、时间、可衡量的细节（不说"体现彰显标志着"）？③关键论断有没有数字、场景或具体物件支撑？
- **典型表现**："加强宣传、完善机制"一句飘过；号召三遍没人知道明天饭怎么吃；形容词撑不住两句追问。
- **方法论对应**：综分误区「对策空泛」；组织误区「动作空泛」「对象笼统」；言语误区「只喊口号不给动作」；common-02 拒绝假大空。

### 1.4 对象感缺失

- **定义**：不知道自己在对谁说话——没认清自身身份权限、没把受众分层、语气腔调与对象场合错位，听着像背稿不像对人说话。
- **判定线索**：①开口前有没有定"我是谁、对谁说、什么场合"？②受众有没有分层（老人/青年/家属/领导，方式各不同）？③称谓和语调换对象时换不换？
- **典型表现**：对老人用口号腔、对领导用对同事的口气；"安抚群众"一句把所有人当整体；全程播音腔复读。
- **方法论对应**：言语审题「对象/场合/身份三样定调子」、误区「调子与场景不符」；人际审题「对象维度」；组织要点2「事前精准锁定对象，不平均用力」。

### 1.5 边界失守

- **定义**：越过权限或底线——拍胸脯承诺做不到/权限外的事、漏掉安全风险或安全顺序颠倒、丢掉题干给定条件或教师注强调的约束。
- **判定线索**：①有没有承诺自己权限外、兑现不了的事（"我不自己拍胸脯应下""不越权收原件"）？②安全风险查了吗、顺序对吗（先查人后修电）？③题干/教师注给定的条件（如"未成年人严禁下水施救"、核心材料不得变通）丢没丢？
- **典型表现**：应急漏掉电梯困人和配电起火；把耐心解释当万能且变通受理条件；宣传里把自救知识讲反。
- **方法论对应**：应急审题第三问「我的权限够不够」、要点1「生命安全绝对优先」；人际「三条底线」；题库教师注「边界提示/安全红线」条目。

### 1.6 收束无力

- **定义**：结尾没有完成闭环——用放之四海皆准的口号收尾、结尾与前文具体问题断开、没交代"怎么算办成了"的检验标准。
- **判定线索**：①结尾是不是换个题目还能原样用的口号？②有没有回扣本期讲的具体问题？③有没有可核对的标准（"看群众办事少跑几趟""看泔水桶里的剩饭少没少"）？
- **典型表现**："相信在各方努力下问题一定得到解决"式万能结尾；说完就完没有闭环；收尾强行拔高喊口号。
- **方法论对应**：综分要点8「收尾从具体问题落到具体判断，不强行拔高」、误区「缺乏记忆点」；应急要点5「善后闭环」、误区「善后无闭环」；自我认知误区「收尾过度拔高」。

## 3. 选题机制（定稿）

选题输入：vault `scripts/tips_index.json`（选题池，读 card_points/stuck_symptom/types/src/note）+ `scripts/progress_tips.json`（done_ids，只读过滤）。流程六步：

1. **卡点入口**：用户指定卡点（六大类名或任一标签）→ 过滤出 `card_points` 命中该卡点且未 done 的技巧；未指定 → 按六大类轮转，建议顺序**破题空泛→内容空洞→结构散乱→对象感缺失→边界失守→收束无力**（理由：读者最痛先教——破题决定第一印象，空话假大空最普遍）。轮转游标不新增状态文件：由 done_ids 对应技巧的 card_points 推断最近一期主卡点，按上述顺序推下一类；该类已无未 done 候选则顺延下一类。
2. **题型过滤**：用户指定题型 → 只在该题型内选；未指定 → 按索引 types 轮转（避免连续同题型），与卡点过滤取交集。
3. **去重约束沿用**：`done_ids` 中的 id 一律过滤；`_meta.dedup_notes` 的分工约束继续生效（如 zw-01 重讲须收窄角度、yy-01/common-03 各管各的）——候选若涉 dedup 条目，展示时注明本期角度与已发布角度的差异。
4. **候选 2-3 个**：每个候选展示四样——治什么卡点（card_points）、读者卡壳表现（stuck_symptom）、本地依据（src 题库文件路径+该篇教师注/思路大纲要点）、对应方法论（src front-matter「方法映射」指向的《各题型方法论》要点）。
5. **弹窗交互**：把候选做成选项弹窗（选项即候选），外加固定项"都不要，换一批"；**不让用户打字**。选"换一批"则排除本轮已展示 id，按同样过滤取次优候选再弹一轮；候选耗尽则如实告知并请用户指定卡点或题型。
6. **选中后**：索引内条目直接进写稿流程；索引外热点（`added:true` 条目及未来新增热点）沿用 added 机制——可入候选但须标注非索引原生条目，发布后按既有流程登记。

## 4. 打标依据方法

每条技巧的打标只从三个本地事实源归纳，不臆造：

1. **索引 note**：该条技巧的一句话定位（导师校准过的口径）。
2. **题库 src 原文**（`source_root` 下对应 md 全文）：题干、思路大纲（破题角度/核心观点/收尾方向）、答题逐字稿示范、教师注（教学提示/边界提示/安全红线——直接指出学生易错点，即该技巧治的卡点）。
3. **对应题型方法论**：src front-matter「方法映射」指向的《各题型方法论》要点与「常见误区」章。

归纳规则：教师注"教学提示"里写明的学生易错点优先；其次取思路大纲破题角度与收尾方向示范的是什么（示范"敢下判断"即治"没下判断"）；方法论误区章可交叉印证。三个来源都支撑不了卡点判断的条目，标"待核实"并在任务报告列明，不硬打。本次 39 条打标（2026-11-20）无"待核实"条目。

## 5. 阶段 2 答题线复用标注

本分类体系阶段 1 只服务技巧线选题。阶段 2 答题线（逐题作答出稿）启用时：答题线按题出题、逐题审稿，**卡点标签不作为答题线选题字段**（答题线不查 tips_index），但六大类分类体系与判定线索供答题线审题五维、写后自检参照（如审稿时对照 1.1-1.6 判定线索逐条核）。复用时以本文件为分类事实源，标签词表可按答题线需要扩充，扩充须回写本文件并同步索引 `_meta.card_point_taxonomy`。
