## 六卡结构（2026-10-11 v3 简洁改版，对齐答一道 Word 模板帖风）

版式原则：对齐《结构化每日一练》Word 模板——每页一个焦点、直白功能标题、无副标、无装饰条幅、内容在剩余版面垂直居中；信息密度做减法，留白即高级。

1. **01-封面**：logo 头（眉标=SERIES_INTRO）→ 「{岗位}岗」Black 132 墨色 + 业务名 Black 104 枣红（居中，超宽自动缩）→ 金短线 → **cover_hook 价值句** Bold 44 枣红（句式「照这 N 步答，考官以为你干过这岗位」）→ 页脚。无 hero 卡、无 chips、无灰字长句。
2. **02-场景**：大标「题目场景」→ 白卡随文字自适应高度并在 480–1330 区域垂直居中（字号 44→30，≤4 行倾向）；无提示条。
3. **03-步骤上 / 04-步骤下**：大标「实操步骤」，徽章标范围（步骤 1–4 / 步骤 5–7）；步骤卡排版不变（白卡 + 枣红数字方块 + 四字 lead Bold 38 + 展开句 27 折行，档位同前）。无副标。
4. **05-红线**：大标「红线禁区」→ 红系行组在 460–1330 垂直居中（✗ + Bold 36 红字）；无底部警示条。
5. **06-嵌入句**：大标「答题嵌入句」→ 嵌入句白卡（Bold 44→32 自适应折行）→ 米杏假大空对照条（✗ 灰 / ✓ 枣红）→ 枣红 CTA 条（16 岗务实手册 · 看主页 + 品牌副行）。无副标。

## 排版铁律

- 只折行、永不截断：`wrap_text` 像素折行 + 行首避头标点 + 行尾不悬挂开引号/括号（「『（《移入下行）+ 末行孤字借字。
- 折行绘制用 `draw_wrapped`；居中标题 anchor 用 `mm` 且坐标必须是容器几何中心。
- 白卡一律 `shadow_card`（投影 + BORDER 描边）；胶囊宽度随 `tw` 实测。
- 卡 6 CTA 副行用品牌 slogan「先答一道，把最影响得分的地方找出来」，不许与页脚标语同屏重复。
- 所有新增文案字段必须先进 pending schema 过门禁，不许在引擎里硬编码业务内容。
