## 4 道校核清单（生成后必跑）

```python
def verify_v1_2(docx_path: str) -> bool:
    """生成后必跑的 4 道校核"""
    from docx import Document
    doc = Document(docx_path)

    # 1) Heading 1 必须=7（7 大模块章标题）
    h1 = sum(1 for p in doc.paragraphs if p.style.name == "Heading 1")
    assert h1 == 7, f"H1 应=7，实际={h1}"

    # 2) 元信息行（• 知识点/所属模块/难度/考频/题型）每篇 5 行 × 35 篇 ≈ 175
    meta = sum(1 for p in doc.paragraphs
               if p.text.startswith("• ") and any(k in p.text[:10] for k in ["知识点", "所属模块", "难度", "考频", "题型"]))
    assert meta >= 170, f"元信息行 应>=170，实际={meta}"

    # 3) 暗红色记忆提示必须>0
    mnem = sum(1 for p in doc.paragraphs
               for r in p.runs
               if r.font.color and r.font.color.rgb
               and "8B0000" in str(r.font.color.rgb).upper())
    assert mnem > 0, f"暗红记忆提示 应>0，实际={mnem}"

    # 4) 真实 Word 表格必须>0
    tables = len(doc.tables)
    assert tables > 0, f"表格数 应>0，实际={tables}"

    # 5) 元数据残留（v1 优化记录）必须=0
    meta_hits = sum(1 for p in doc.paragraphs
                    if "本讲稿 v" in p.text and "优化记录" in p.text)
    assert meta_hits == 0, f"元数据残留 应=0，实际={meta_hits}"

    return True
```

## 反例（v1.2 历史教训·2026-06-11 沉淀）

1. **R7 反例·文件 H1 重复**：v1.1 之前脚本里 `render_md_file` 把文件名当 H1，**同时** `render_h1_section_with_meta` 把文件内 `# 举一反三...` 也当 H1——**一个篇渲染了 2 次 H1**。修法：文件内 H1 标题**跳过**（与 H2 篇名重复）。
2. **R8 反例·`is_question_line` 假阴性**：v1.1 之前用 `**第N题**` 含 `**` 模式匹配——但 strip_md 后 `**` 没了，**永远不匹配**。修法：宽松正则（去掉 `**`），匹配 `^第\d+题[（(].*?[）)]\s*[：:]`。
3. **R9 反例·脚本路径 `01\笔试讲义` vs `01_笔试讲义`**：Windows bash 路径里有 `\u4e0a` 转义陷阱——`bash` 直接 read 路径用 `r"C:/..."` 正斜杠**或**先 `ls` 验证再调脚本。
4. **R10 反例·元信息行被静默 skip**：v1.1 之前 `if text.startswith(">"): continue` 把 `> **知识点**：` 整行跳过了！修法：**先收集**到 `meta_lines`，再渲染。**这是元信息 0 → 175 的根因**。
5. **R11 反例·clean_md_content 兼容性差（v1.5 实战，2026-06-15）**：脚本正则 `r"^>\s*\*\*本讲稿 v\d+(\.\d+)?\s*优化记录\*\*"` 严格要求 `>` 前缀 + `**` 加粗——但 AI 实战稿常漏 `>`+`**`（如篮球 03/04 写 `本讲稿 v1.0 优化记录： - v1.0：...`），**首跑残留 2 处**。修法：兼容正则 `r"^(?:>\s*)?(?:\*\*)?本讲稿\s*v\d+(\.\d+)?\s*优化记录"`。**根因**：SKILL 模板规定 `> **本讲稿 v? 优化记录**`（带 `>` + 加粗），但写稿时"格式不对也算对"——clean 函数**不感知 markdown 加粗配对**。**自验**：跑后必查 `meta_hits == 0`。
