### E. 拓展盒审计 + 补漏工作流(2026-06-25 新增)

**触发**:🆕 **每次生成完讲稿后自动启动**(2026-06-25 升级)
- **单篇触发**:每篇讲稿写完跑 R1 后,自动扫描源讲义中本篇对应章节的所有"知识拓展"标记
- **模块触发**:每模块 8 篇全部写完,自动汇总该模块所有拓展盒覆盖情况,生成审计报告
- **用户可手动重跑**:"再跑一次拓展盒审计" / "检查拓展盒覆盖"

**5 步流程**:

1. **定位模块边界**:
   ```powershell
   Select-String -Path 讲义库.md -Pattern "^## 第[一-七]模块" 
   ```
   找到模块 L1-L2(模块起点-下模块起点)

2. **提取拓展盒**:
   ```powershell
   Select-String -Path 讲义库.md -Pattern "^\| (拓展延伸|知识拓展|知识链接|补充阅读) " | Where-Object { $_.LineNumber -ge L1 -and $_.LineNumber -lt L2 }
   ```

3. **交叉审计**:对每条拓展盒用核心关键词在对应输出文件 grep 验证

4. **补丁**:
   ```js
   // mcp__node_repl__js
   const { readFileSync, writeFileSync } = await import("node:fs");
   let txt = readFileSync(filePath, "utf-8");
   txt = txt.slice(0, idx) + newSubSection + txt.slice(idx);
   writeFileSync(filePath, txt, "utf-8");
   ```
   在每个文件 `---\n\n## 三、典型例题` 标记前插入新子小节

5. **R1 验证**:全模块跑 `r1_self_check.py` 必须 R1=0

### F. JS 写文件踩坑清单(2026-06-25 沉淀)

| 坑 | 触发 | 解决 |
|----|------|------|
| 1 | 模板字符串 box-drawing 字符(├ │ └)→ JS 解析 "Illegal character" | 用 ASCII 或分离代码块(`+`+"`"+ ``) |
| 2 | writeFileSync 重复声明 | `mcp__node_repl__js_reset` 重置 kernel |

| 5 | 路径用 `\` 反斜杠 | 统一 `C:/...` 正斜杠 + `String.raw` |

### G. 记忆口诀 7 种记忆术(只为 4 个重点服务)

| 记忆术 | 例子(实战出处) |
|--------|----------------|
| 谐音 | "上级公开争饭" = 竞技 6 大特点(赏/集/公/开/争/范) |
| 语意 | 5 种力量训练语意编组(大体积/快速度/爆力×速/相扣体/耐多次) |
| 首字连词 | "形功素"= 身体形态+身体机能+运动素质 |
| 关键词 | 体能 4 大意义 → "提承稳延" |
| 缩减 | 7 大特点压成 7 字"炼趣规综教虚非" |
| 编歌诀 | 故事化口诀(如"学校体育 vs 社区体育 5 维区别") |
| 缩减排比 | 平行结构口诀(如儿童 4 类不宜"负/憋/长/时机") |

**4 类重点服务对象**:
1. 核心定义/概念(必背)
2. 大量易混项(必背)
3. 多维对比(必背)
4. 易错点串联(必背)
