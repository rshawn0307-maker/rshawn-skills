# md 转 Word 通用提示词 v1

> 用途：把一批 Markdown 讲稿汇编为 Word 讲义。本文件是可直接复制给任意 agent 的提示词；不含路径、不含技能名，只描述转换要求。

---

请将一批 Markdown 讲稿汇编为两个 Word 文档（教师版、学生版），按以下要求执行。

## 一、版本差异

1. **教师版**：保留全部正文内容，包括所有 `> 🎤 授课提示：…` 教学提示块。
2. **学生版**：面向学生自学，必须剔除以下教师/编辑专用内容：
   - 所有 `> 🎤 授课提示：…` 块；
   - 每篇末尾的「学习导航」整节（讲义来源、背诵手册、上一篇、下一篇、本模块目录、本模块来源等导航元数据及其子标题）；
   - 所有编辑备注类内容（如「本讲稿 vN 优化记录」块、「修订说明」节）。
3. 两版都保留：知识点讲解、例题、变式题、答案与解析、易错分析、记忆口诀、知识拓展等学生需掌握的内容。

## 二、内容清理（两版统一）

1. 删除 YAML frontmatter 与属性区（title/subject/module/level/frequency/question_types/updated/tags 等）；
2. 删除 Obsidian 双链语法：`[[目标|显示文本]]` 只保留“显示文本”；无显示文本的 `[[路径]]` 整段删除；删除 `![[]]`、`#标签` 类标记；
3. 删除 Markdown 分隔线（`---`）、代码围栏标记（仅删标记）；
4. 表格中内容仅为“#”的列头改为“序号”；
5. 代码块分类处理：知识树/关系图/时间线等结构图代码块 → 按《md代码思维导图转图片_v1.md》转成图片后插入；公式等非图代码块保留为等宽样式段落。

## 三、Word 格式要求

1. 标题使用 Word 内置 Heading 1/2/3（必要时 Heading 4），保证可生成目录；文档开头插入目录域（`TOC \o "1-3"`）；
2. 表格使用 Word 原生表格：固定列宽且各列宽度合计与页面可用宽度一致、表头行浅蓝底纹并设为跨页重复表头、单元格内边距统一、不得保留任何 Markdown 表格符号；
3. 列表使用真实 Word 编号/项目符号定义，不得用“-”“1.”等手工字符冒充；
4. 题目与答案/解析之间留明显分隔（答案块/解析块增加段前段后间距，可加浅底纹）；
5. 引用块（讲义原文、授课提示）用缩进+浅底纹样式区分；
6. 页面排版：正文约 11pt、行距约 1.25、段后约 6pt；标题层级用色区分（如 H1/H2 蓝色、H3 深蓝）；
7. 中文字体需显式设置 East Asian 字体（如“宋体/Songti SC”），避免在 Word/WPS 中打开时中文回退异常；页眉放文档名、页脚居中页码。

## 四、对抗式审查（生成后逐项检查）

1. 全文（含表格单元格）不得残留 Markdown 语法：行首 `#`、`**`、`|---|`、` ``` `、`- [ ]`、孤立“#”单元格等；
2. 不得残留 Obsidian 链接语法（`[[`、`]]`）；
3. 标题必须映射为 Word Heading 样式（检查层级数量与样式名）；
4. 学生版必须 0 处“授课提示/🎤”、0 处“学习导航/讲义来源/背诵手册/上一篇/下一篇”；教师版必须保留授课提示；
5. 两版均不得出现 frontmatter、优化记录、修订说明等编辑残留；
6. 所有知识树/关系图/时间线代码块均已转图，正文不得残留结构图围栏文本；抽查图片首行文字无裁切、无边缘贴边。

## 五、渲染核查

1. 用 Word/LibreOffice 渲染抽查封面、目录、正文、表格页、含图页、末页：中文无乱码/豆腐块、无溢出/截断/重叠、表格不破版、图片完整显示且首行文字无裁切；
2. 若渲染环境缺少中文字体导致豆腐块，先注入系统中文字体目录再渲染，不得以缺字体误判为文档缺陷；
3. 目录为 Word 域，生成后需在 Word 中“更新域”显示，渲染工具中显示占位文本属正常。
