```
党政机关公文（GB/T 9704-2012，国标）
  纸张        A4，210mm × 297mm
  页边距      上 37mm、下 35mm、左 28mm、右 26mm
  版心        156mm × 225mm，每面 22 行、每行 28 字
  正文        三号仿宋（16pt），每段左空二字，回行顶格
  主送机关    标题下空一行，居左顶格，回行仍顶格（不是左空二字！）
```

## 二、国标已规定、不需要问用户的项

以下数值直接执行，不要拿去问用户：

| 项 | 值 | 条款 |
|---|---|---|
| 天头（上白边） | 37mm ± 1mm | §5.2.1 |
| 下白边 | 35mm | §5.2.1 |
| 订口（左白边） | 28mm ± 1mm | §5.2.1 |
| 右白边 | 26mm | §5.2.1 |
| 版心 | 156mm × 225mm | §5.2.1 |
| 每面行数、每行字数 | 22 行 × 28 字 | §5.2.3 |
| 正文与各要素默认字体字号 | 3 号仿宋 | §5.2.2 |
| 文字颜色 | 黑色 | §5.2.4 |
| 正文格式 | 每自然段左空二字，回行顶格 | §7.3.3 |
| 主送机关 | 编排于标题下空一行位置，居左顶格，回行时仍顶格 | §7.3.2 |
| 附件说明 | 正文下空一行左空二字编排「附件」二字，后标全角冒号和附件名称；**名称较长需回行时，与上一行附件名称的首字对齐**（悬挂缩进） | §7.3.4 |
| 发文机关署名与成文日期（加盖印章） | 成文日期一般右空四字编排；单一机关行文时，在成文日期之上、以成文日期为准居中编排发文机关署名 | §7.3.5.1 |
| 发文机关署名与成文日期（不加盖印章） | 署名右空二字，日期在署名下一行、首字比署名首字右移二字；日期长于署名时，日期右空二字并相应增加署名右空字数 | §7.3.5.2 |
| 红头位置 | 上边缘距版心上边缘 35mm | §7.2.4 |
| 红头颜色 | 红色 | §7.2.4 |
| 分隔线 | 发文字号下 4mm，与版心等宽，红色 | §7.2.7 |
| 标题 | 2 号小标宋，红线下空二行，居中；**回行时词意完整、排列对称，排列使用梯形或菱形**（生成端会人工断行，不再是「排满一行就断」） | §7.3.1 |
| 发文字号 | 红头下空二行，居中 | §7.2.5 |
| 上行文发文字号 | 居左空一字，与最后一个签发人姓名处在同一行 | §7.2.5 |
| 签发人 | 「签发人」三字加全角冒号和姓名，居右空一字，编排在发文机关标志下空二行位置；三字用 3 号仿宋、姓名用 3 号楷体 | §7.2.6 |
| 页码 | 4 号半角宋体，单页居右空一字、双页居左空一字，一字线距版心下边缘 7mm | §7.5 |
| 版记分隔线 | 与版心等宽；首条与末条用粗线 0.35mm，中间用细线 0.25mm | §7.4.1 |
| 版记字体 | 抄送、印发机关与印发日期均用 4 号仿宋；抄送左右各空一字，印发机关左空一字、印发日期右空一字 | §7.4.2、§7.4.3 |
| 抄送机关回行 | 「抄送」二字后加全角冒号和抄送机关名称，**回行时与冒号后的首字对齐**（悬挂缩进） | §7.4.2 |
| 版记印发日期 | 年、月、日标全，**月、日不编虚位**，日期后**加「印发」二字**（如「2026年9月16日印发」） | §7.4.3 |
| 装订 | 左侧装订 | §6.3 |

## 三、必须问用户的项

标准没有写死、或存在多种选择：

| 项 | 为什么问 | 建议默认 |
|---|---|---|
| 发文机关名称（全称或规范化简称） | 标准未规定内容 | 必填 |
| 是否加「文件」二字 | 标准允许两种写法 | 加 |
| 红头字号 | §7.2.4 只说「以醒目、美观、庄重为原则」，未给字号 | 按机关名长度推荐：单行 ≤ 20 字用初号 42pt，超过则逐级下调 |
| 是否联合行文 | 影响机关名排序与「文件」位置 | 否 |
| 发文字号内容（机关代字、年份、顺序号） | 标准未规定内容 | 必填 |
| 是否上行文 | 上行文发文字号居左空一字，且须有签发人 | 否 |
| 签发人姓名 | 仅上行文需要，用 3 号楷体 | 无 |
| 是否加盖印章 | §7.3.5.1（盖章）与 §7.3.5.2（不盖章）规定的署名与成文日期位置**不一样**，必须先问清 | 盖章（红头文件绝大多数要盖章） |
| 份号、密级和保密期限、紧急程度 | 可选要素 | 无 |
| 是否要版记 | 版记在公文最后一面底部，不是每份都要 | 要（正式文件建议要） |
| 印发机关、印发日期、抄送范围 | §7.4 只规定版记怎么排，没规定写什么 | 必填印发机关与日期；抄送可空 |
| 字体缺失时 | 本机通常缺仿宋_GB2312 与方正小标宋简体 | 逐个问用户：装字体，或指定本机已有的（写进 `resolved`） |

## 五、载体适配注意

| 项 | DOCX | PDF |
|---|---|---|
| 全部页面参数 | 写入 `w:sectPr` | 通过 LibreOffice 保留 |
| 奇偶页不同页码 | 需要 `w:evenAndOddHeaders` | 保留 |
| 红头与分隔线 | 红头为红色文本段落；分隔线用段落红色下边框模拟 | 保留 |
| 一字线（页码左右短横） | 用半角连字符或 `—` 环绕数字实现 | 保留 |

**公文只能出纸媒格式。** 公文是纸媒体裁，开本、页边距、红头、版记、页码一字线全部依赖固定页面；用户若要求电子书之类的流式版本，如实说明这些参数会全部失效，做不到，而不是勉强生成一份。

## 六、常见错误提醒

- `〔〕` 是六角括号，不是 `[ ]`、`【 】` 或 `（）`
- 发文顺序号不编虚位：`1` 不写成 `01`
- 顺序号后要加「号」字
- 成文日期的月、日不编虚位：`9 月 1 日` 不写成 `09 月 01 日`
- 正文是每段**左空二字**（不是首行缩进 2 字符的通用写法，虽然效果类似，但公文用「左空二字」表述）
- 层次序数顺序是「一、」→「（一）」→「1.」→「（1）」，不可跳级混用
- 发文机关名称、发文字号（机关代字＋年份＋顺序号）、署名与成文日期是公文成立的要素，
  缺一项 `build_docx.py` 就中止（退出码 3），不许留空生成、更不许编造
