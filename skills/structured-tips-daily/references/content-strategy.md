# 内容策略与考官视角（references/content-strategy.md）

> 本文件在 SKILL.md 步骤 2（写内容草稿）和步骤 2.5（祛 AI 味儿）时读取。
> 融合"上岸过来人 + 考官视角"定位：内核是考官视角的答题技巧拆解，外壳按小红书爆款节奏打磨。

## 考官视角核心

**核心定位**：本号不是教"如何答一道题"，是**站在考官视角剖析"一道题应该怎么答"**——把"考官想听什么"翻译成"考生能用的答题技巧"。

### 考官真正想听什么

公务员结构化面试，**1 个考官 1 天听 30+ 个考生，平均 1.5 分钟定生死**。他们要的不是"标准答案"，是：

- **有观点**：敢下判断，不中庸。"我怎么看这件事" > "利弊分析"
- **有逻辑**：观点有支撑链，但逻辑≠"首先/其次/最后"流水线，是有"机制阐释"能力
- **有表达**：语言鲜活有节奏，读起来像"真人在讲"
- **有深度**：能看到"机制层"（为什么这样），不是停在"现象层"（这样不好）
- **可操作**：对策要能落地——"街道设 1 个'老人陪同岗'，每天上午 9-11 点"，不是"加强宣传"
- **接地气**：用"街道办""90 后网格员""社区民警"具象词，不是"基层干部""人民群众"

### 考官最反感的 5 种答法（避坑反面）

| 类型 | 典型表现 | 为什么差 |
|---|---|---|
| **假大空** | "体现了以人民为中心的发展思想" | 没具体指向，说了等于没说 |
| **套路化** | "凡事预则立，不预则废"开场 | 30 个考生 25 个这么说，考官已麻木 |
| **空喊口号** | "加强、完善、推进、落实"四个动词堆 | 没动作主语、没时间、没可衡量 |
| **辩证式中庸** | "这事有利有弊，要辩证看" | 等于没观点，不敢站队 |
| **背模板** | "戴了三个帽子：理论/实践/个人" | 一听就是培训班，扣差异化分 |

**技巧教学型骨架的角色**：骨架是脚手架，观点和论证才是肉。只要有 1 个让考官"眼前一亮"的判断，整体就立住了。

## 小红书表达规范（必读）

> 本号内容是发在小红书上的图文帖子，不是公众号讲义。**考官视角拆解是内核，小红书节奏是外壳**：深度不能丢，表达必须按平台习惯来。

### 1. 标题钩子（tip_title）

- **≤20 字**（脚本硬上限），必须含**数字 / 反差 / 悬念 / 利益**之一。
- 禁止纯主题词：`"应急应变"` 不合格；`"应急应变别再平均用力，先排序再出招"` 合格。
- 封面文本框只放标题本身，不写"每日一练""第 N 期"等栏目词。

### 2. 开场 3 秒（tip_intro）

- 用**判断句**直接给观点；"不是 X，是 Y"全篇最多 1 次，开场用过后面不再用。
- 带**真实考场细节**：考官一天听 30+ 人、1.5 分钟定生死、评分表维度、低头看表。禁止空喊"考官想听的是…"。

### 3. 段落节奏（所有正文段）

- **单段 ≤4 行，行内 ≤30 字**；短句 8-20 字为主，长句必须拆。
- 数字一律阿拉伯数字（"30 个考生"不写"三十个考生"）。
- emoji 每段 ≤2 个，限调色板：`❗️ 🙅 ❌ ✅ 📌 💡 ⏰ 🗣`；禁止无意义堆砌。
- 每屏一个核心信息，靠短句呼吸，不靠"第一/第二/第三"连接。

### 4. 普通 vs 高分对照（本 skill 特色）

- `case_normal`（普通答法）给**考生常见的低分答法片段**，越真实越好（读者会有"这就是我"的共鸣）。
- `case_normal_note` 点评为什么让考官减分，用"考官内心：又来一个背模板的"这种有画面的写法。
- `case_high`（高分答法）给同题的高分答法，**有明确先后顺序、具体动作抓手**，读者能直接抄。
- `case_high_note` 点评高分在哪，用"考官内心：这个人有判断力"。

### 5. 避坑提醒（pitfalls）

- **2-5 句"绝对不能说的官话"**（如"基层要敢于担当""减负不减责"）。
- 这是"赚到感"关键——读者觉得"学到课本外的东西"。

### 6. 话题标签（hashtags）

- 5-8 个，空格分隔，每个以 `#` 开头。
- 固定 3 个：`#公考面试 #结构化面试 #上岸`；其余按当期题型/主题补 2-5 个（如 `#应急应变 #答题技巧 #面试逆袭`）。
- 标签写实，不蹭与内容无关的热门标签。

### 7. 数据纪律

- 数字钉子必须**可核验**：公开来源或有出处，或明确标注"举例"。
- **禁止编造百分比和统计**（"73% 不会用"必须有出处，否则写"我见过的大多数窗口…"并标举例）。

### 8. 听感自检

- 写 JSON 前把全文大声读一遍：读起来像人话才过。
- 书面连接词（此外/值得注意的是/与此同时）、"第一步/第二步"腔调、破折号滥用，一律改口语。
- 破折号一律清零，用逗号或句号断句。

## 内容算法

### 1. 钩子反转（开头 3 秒决定完读率）

- **"不是 X，是 Y"** 对立反转（**最常用**，全篇最多 1 次）
- **"X 发了上百份，Y 反而越来越多"** 事实反转
- **"X 装了 Y，Z 测了 W"** 对比反转

### 2. 金句密度

- **几乎每节结尾都有一句可截屏**——截图率=收藏率=算法权重。
- **金句公式**："X 不是 Y，是 Z" / "X 不是为了 Y，是为了 Z" / "X 决定 Y"

### 3. 数字钉子

- 用具体数字撑观点："留痕不留绩""上百个 APP""40 多个政务 APP 每天打卡"。
- 数字让"机制层"分析有抓手，不空转。

## 去 AI 化红线

**流程**：生成草稿 -> 按 human-writing 规则自查 -> 改写问题片段 -> 入 JSON。

**绝对禁止的 AI 模式**（公考面试语境下高危版）：

| 类别 | 红线示例 | 公考面试改写 |
|---|---|---|
| **填充短语** | "为了实现这一目标""值得注意的是" | "为了 X" / "X 数据显示" |
| **AI 词汇** | 此外、至关重要、深入探讨、强调、培养、获得、突出、复杂性、关键（形容词）、格局 | 用具体动词："培养"->"教" / "格局"->"布局" |
| **否定式排比** | "不仅...而且..." "这不仅仅是...而是..." | 改直接陈述："A 是 B" 而非 "A 不仅是 B，更是 C" |
| **三段式法则** | 强行把 2 件事扩成 3 件凑数 | **2 件就 2 件，4 件就 4 件，不要凑 3** |
| **破折号** | "--" 出现 | 一律清零，改逗号或句号 |
| **粗体滥用** | 1 段 3-4 个重点词 | 粗体只用于"金句"和"关键数字" |
| **否定式排比钩子** | "不是 X，是 Y" 套 3 段 | **保留 1 段**作开篇钩子即可 |
| **模糊归因** | "专家认为""观察者指出" | 给出具体出处或直接删 |
| **合作交流痕迹** | "希望对您有帮助""请我告诉" | 教程化语言禁止 |
| **过限定** | "可能会""或许可以" | 公考要敢下判断 |
| **通用积极结论** | "未来可期""前景光明" | 用具体行动或时间点替换 |

**特别禁用公考 AI 高危词**（一字不差）：
- **"体现/彰显/凸显"** -> 改 "X 表明" / "X 是因为" / 直接说事实
- **"深入推进/全面落实/持续优化"** -> 给出谁、什么时间、做什么
- **"多措并举/综合施策/协同推进"** -> 列出具体几条
- **"切实保障/有效提升/有力推动"** -> 给出可量化指标

## 公考词汇合规

| 类型 | ✅ 用 | ❌ 别用 |
|---|---|---|
| **政策概念** | "放管服改革""一网通办""网格化治理" | 自创缩写、没出处概念 |
| **角色** | "街道办""90 后网格员""社区民警""驻村第一书记" | "基层干部""人民群众""相关部门" |
| **动作** | "设 1 个'陪同扫码岗'""保留 3 个现金窗口" | "加强 / 完善 / 推进 / 落实" |
| **数据** | "60 岁以上 73% 不会用（有出处）" | "绝大多数""大部分""不少" |
| **判断** | "73% 不会 ≠ 73% 不想学" | "X 是因为 Y" 的伪因果 |

## 金句公式

**好金句 3 特征**：
1. **有判断**——"给翻译层，不给长衫"（不是"我们要重视教育"）
2. **有对比**——"不是 X，是 Y"（一个就够，别 3 段都用）
3. **有具体**——"凌晨 3 点的健康码"（不是"深夜的守候"）

**反面金句**（AI 味儿重）："在 XX 的道路上，我们任重道远" / "时代是出卷人，我们是答卷人"。

## 选题策略

**不预设固定选题优先级**——每期开跑时按步骤 1 查索引：

1. **用户指定题型** -> 过滤索引该题型
2. **用户未指定** -> 按题型轮转，配合近 1-2 周公考热点
3. **避免**过于专业的岗位题材（除非用户指定）
4. **每次选 2-3 个**让用户选择

**历史选题参考**（仅做避重参考，不作为优先级排序）：

| 主题 | 题型 | 反常识破题 |
|---|---|---|
| 指尖形式主义 | 综合分析 | 考核方式在逼基层装忙 |
| 应急处突排序 | 应急应变 | 先排序再出招，别平均用力 |
| 老同事不规范 | 人际沟通 | 尊重在前，沟通有方，规范兜底 |
| 调研价值转化 | 组织计划 | 摸清需求是为了精准供给 |
| 优缺点认知 | 自我认知 | 优秀落地岗位，缺点有改进动作 |
| 演讲先共情 | 言语表达 | 从生活场景切入，不念文件 |
