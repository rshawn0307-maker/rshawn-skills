# 体育试讲稿生成器

## 适用场景

当用户需要基于人教版《体育与健康》教材（或其他版本教材）生成体育试讲稿项目时调用本skill。覆盖以下场景：
- 开发新的运动项目（如篮球、排球、武术等）
- 为已有项目新增子技术
- 对现有试讲稿进行横评和修复
- 切换教材版本重新生成试讲稿

## 前置条件

- 用户提供教材文件（MD格式，放置在工作目录或attachments目录）
- 工作目录下存在以下约束文件（首次使用时由本skill指导创建）：
  - `共性约束_v1.0.md` — 结构/格式/评分锚点/禁忌清单
  - `横评Agent设计_v1.0.md` — 评估维度/流程/返工规则
  - `产品内容大纲_v1.0.md` — 全项目子技术清单

## 工作流程总览

```
Phase 1: 项目初始化 → Phase 2: 子技术识别 → Phase 3: 并行生产 → Phase 4: 六维度横评 → Phase 5: 问题修复 → Phase 6: 备考讲义生成
```

每个Phase完成后需更新进度文件，确保可断点续跑。

## Phase 2: 子技术识别

### 2.1 教材分析流程

1. 读取教材MD文件，提取技术教学内容
2. 按教材章节结构梳理技术体系
3. 对照难度水平分类（水平二★★ / 水平三★★★ / 水平四★★★★）

### 2.2 子技术筛选原则

**纳入标准**：
- 人教版教材中明确列出的运动技术
- 可在10分钟试讲中完整呈现的技术
- 有独立教学价值的技术（非辅助动作）

**排除标准**：
- 纯理论、安全保护方法、战术配合
- 过于基础的内容（如握拍、站位等非技术教学项）
- 试讲场景难以呈现的技术（如需要专业器材或对抗场景）
- 套路动作数量过多，10分钟试讲难以完整呈现的

### 2.3 子技术清单格式

每个子技术需确定5个属性：

| 属性 | 说明 | 示例 |
|------|------|------|
| 编号 | {项目编号}-{两位序号} | 10-03 |
| 名称 | 教材标准术语 | 冲拳 |
| 类别 | 技术分类 | 基本手法 |
| 难度水平 | 水平二★★/水平三★★★/水平四★★★★ | 水平二（★★） |
| 教材定位 | 教材中的章节位置 | 第三章第二节 二、长拳基本技术·2.基本手法（1） |

## Phase 3: 并行生产

### 3.1 生产Agent分组策略

- 每个生产Agent负责3-6个子技术（即12-24份交付物）
- 按技术类别分组（如基本技术类、套路类），确保组内子技术有关联性
- 启动2个并行生产Agent，均衡分配工作量

### 3.2 每个子技术的4份交付物

| 交付物 | 文件名格式 | 内容要求 |
|--------|----------|---------|
| 教学设计 | `{项目编号}_{项目名}_{子技术编号}_{子技术名称}_教学设计_v1.0.md` | 教学目标、教学重难点、运动负荷预估、教学流程概要 |
| 试讲稿 | `{项目编号}_{项目名}_{子技术编号}_{子技术名称}_试讲稿_v1.0.md` | 逐字逐句完整试讲内容，含口令、交互动作标注、评分锚点 |
| 队形图 | `{项目编号}_{项目名}_{子技术编号}_{子技术名称}_队形图_v1.0.md` | 各环节队形布局说明、调动路线、站位图 |
| 自检表 | `{项目编号}_{项目名}_{子技术编号}_{子技术名称}_自检表_v1.0.md` | 21项评分锚点逐项自检、字数统计、时长核对 |

### 3.3 试讲稿结构约束（硬性）

#### 四环节时长刚性约束

| 环节 | 时长 | 字数区间 | 核心任务 |
|------|------|---------|---------|
| 开始部分 | 1分钟 | 180-220字 | 集合整队、考勤报告、宣布内容 |
| 准备部分 | 2分钟 | 360-440字 | 一般性准备活动（热身游戏）+ 专项准备活动（自编热身操） |
| 基本部分 | 6分钟 | 1080-1320字 | 观察探究→示范讲解→3层练习→展示比赛 |
| 结束部分 | 1分钟 | 180-220字 | 放松活动、课堂小结、回收器材 |
| 合计 | 10分钟 | 1800-2200字 | - |

#### 开始部分6个固定动作（按序执行）

1. 集合整队（口令洪亮、手势明确）
2. 考勤报告（与体委互动，模拟报数）
3. 师生问好（鞠躬，展示教态）
4. 检查服装（口袋尖锐物品、运动着装）
5. 安排见习生（身体不适者旁听）
6. 宣布内容（情境导入引出课题，不得用干巴巴的"今天我们学XX"）

#### 准备部分两类准备活动

- 一般性准备活动（约1分钟）：以热身游戏为主，需有信号反应或方向变化元素
- 专项准备活动（约1分钟）：自编热身操，4个8拍为单元，融入主教材关节活动

#### 基本部分"学练赛评"完整链条

| 子环节 | 建议时长 | 必须包含 |
|--------|---------|---------|
| 观察探究 | 1分钟 | 挂图引导+2个观察问题+小组讨论+自主尝试 |
| 动作示范与讲解 | 1分钟 | 动作要点（≥3点）+ 口诀（4-8字）+ 示范面说明（正面/侧面/背面）+ 站位说明 |
| 组织练习 | 3分钟 | 3层递进练习：第一层固定条件单一动作→第二层增加变化条件（附纠错表）→第三层按水平分组分层（各组难度要求不同）+ 每层安全提示 |
| 展示或比赛 | 1分钟 | 比赛名称+活动方法+评价方式 |

#### 结束部分3个固定动作

1. 放松活动（针对性放松，与主教材负荷互补）
2. 课堂小结（三维素养显性化：运动能力/健康行为/体育品德）
3. 回收器材、下课

### 3.4 格式约束

#### 元信息块（每个文件头部）

```
项目: {项目名}　项目编号: {编号}　产物类型: {类型}　版本: v1.0　约束版本: v1.0　生成时间: YYYY-MM-DD HH:MM
```

#### 口令标注

- 格式：`[口令]口令内容`
- 所有口令必须可直接念出，不得用占位符
- 练习口令须有预备信号（如"预备——开始"）
- 队形调动须有标准口令（基准+方向+距离）

口令分类要求：

| 口令类型 | 必须包含的要素 | 示例 |
|---------|--------------|------|
| 集合口令 | 队列形式+动作指令 | [口令]全体都有，成四列横队集合！立正，向右看--齐！向前看，稍息 |
| 练习口令 | 预备信号+执行信号 | [口令]预备--开始！……[口令]停！ |
| 队形调动 | 基准+方向+距离 | [口令]以中间同学为基准，成体操队形散开！ |
| 下课口令 | 标准收束 | [口令]立正！同学们再见！ |

#### 评分锚点标注

- 格式：`> 评分锚点：[评分项] - [得分动作]`
- 覆盖率≥90%（共21项锚点，标注≥19项）

评分锚点清单（共21项）：

| 环节 | 评分项 | 得分动作 |
|------|--------|---------|
| 开始部分 | 教学组织 | 集合整队口令洪亮、队列整齐、6个固定动作完整 |
| 开始部分 | 安全管理 | 检查服装口袋尖锐物品、安排见习生 |
| 开始部分 | 教态仪表 | 师生问好鞠躬、精神饱满、着装规范 |
| 开始部分 | 语言表达 | 情境导入引出课题，语言清晰有感染力 |
| 准备部分 | 教学组织 | 热身游戏规则清晰、队形调动有序 |
| 准备部分 | 运动负荷 | 专项热身操针对主教材关节，4个8拍编排完整 |
| 准备部分 | 安全管理 | 热身前提示安全注意事项 |
| 准备部分 | 教法运用 | 热身游戏有设计感，体现趣味性和亮点 |
| 基本部分 | 讲解能力 | 技术要点准确、口诀化总结（4-8字） |
| 基本部分 | 示范能力 | 示范面正确、站位合理 |
| 基本部分 | 教法运用 | 练习手段递进（至少3层）、学练赛评完整 |
| 基本部分 | 教学组织 | 分组练习组织紧凑、队形调动简洁 |
| 基本部分 | 运动负荷 | 练习密度≥50%、运动密度≥75%、心率140-160 |
| 基本部分 | 错误纠正 | 集体纠正共性问题+个别纠正典型错误，附纠错表 |
| 基本部分 | 安全管理 | 保护帮助到位、场地器材检查、安全提示 |
| 基本部分 | 教学设计 | 情境创设合理、区别对待有体现 |
| 结束部分 | 运动负荷 | 针对性放松活动，与主教材负荷互补 |
| 结束部分 | 综合素质 | 三维素养小结（运动能力/健康行为/体育品德） |
| 结束部分 | 教学组织 | 回收器材有序、下课口令规范 |

（注：基本部分含8项，但实际标注时"安全管理"可在多个练习环节中分别标注，总计21项锚点）

#### 交互动作标注

用（）标注预期学生反应或教师动作。

示例：
- （体委报告出勤人数）
- （教师完整示范一次）
- （学生模仿练习，教师巡视）

#### 标题层级

- `## 环节名` → `### 子环节`（不得使用时间戳作为主标题，时间戳可作为环节标题后的括注）

#### 术语规范

所有运动技术术语必须符合人教版教材表述，不得口语化篡改。

### 3.6 健康课程特殊约束

健康课程不涉及运动技能教学，核心授课形式为**综艺式互动游戏**：

基本部分四结构调整为：

| 子环节 | 建议时长 | 必须包含 |
|--------|---------|---------|
| 游戏导入 | 1-1.5分钟 | 综艺式互动游戏开场，引出健康主题（游戏名称+规则+学习目标） |
| 游戏探究 | 2分钟 | 主体游戏环节，学生通过闯关/分类/抢答等形式发现健康知识（≥3个知识要点） |
| 游戏拓展 | 1.5-2分钟 | 进阶游戏或情境模拟，巩固知识并迁移到生活场景 |
| 总结评价 | 1分钟 | 知识回顾+行为习惯养成建议 |

其他调整：
- 至少设计2个游戏环节（导入游戏+主体游戏或拓展游戏）
- 每个游戏必须承载明确的健康知识点，游戏结果自然引出知识要点
- 准备部分用健康知识抢答或趣味问答替代身体活动热身
- 结束部分用课堂静心收束替代放松活动
- 课堂小结须结合游戏成果回顾知识点
- 三维素养调整为：健康知识/健康行为/健康品德

## Phase 4: 六维度横评

### 4.1 评估维度表

| 维度 | 权重 | 1分 | 3分 | 5分 |
|------|------|-----|-----|-----|
| 教学设计合理性 | 20% | 环节缺失或时长严重失衡 | 结构完整但缺乏层次 | 结构完整且层次清晰递进 |
| 口令规范性 | 15% | 多处模糊口令 | 口令基本清晰但欠精炼 | 口令准确精炼可直接执行 |
| 安全组织 | 20% | 存在安全隐患 | 安全但组织松散 | 安全且组织紧凑高效 |
| 评分锚点覆盖率 | 15% | <60%（<13项） | 60-89%（13-18项） | ≥90%（≥19项） |
| 差异化亮点 | 15% | 无亮点 | 有1处亮点 | ≥2处创新且合理亮点 |
| 可操作性 | 15% | 考生无法直接使用 | 需少量调整可用 | 拿来即可直接照念 |

### 4.2 各维度评分细则

**教学设计合理性（20%）**：
- 5分：四环节齐全、时长1+2+6+1合规、3层递进练习+1比赛完整呈现、分层练习体现区别对待
- 3分：四环节齐全且时长合规，但练习层次不足3层或缺少分层练习或比赛环节缺失
- 1分：四环节缺失任一环节；或时长之和不等于10分钟；或基本部分未呈现学练赛评完整链条

**口令规范性（15%）**：
- 5分：所有[口令]标记内容准确精炼、可直接念出、有预备信号和执行信号、队形调动口令标准
- 3分：口令基本清晰但个别口令欠精炼；或队形调动口令不够标准
- 1分：出现3处以上模糊口令；或口令使用占位符；或缺少预备信号

**安全组织（20%）**：
- 5分：安全措施到位、保护帮助规范、组织紧凑高效、安全提示充分
- 3分：无安全隐患但组织松散；或安全提示不够充分
- 1分：存在安全隐患（相向投掷/无保护高器械）；或体操未安排保护帮助；或投掷未统一方向

**评分锚点覆盖率（15%）**：
- 5分：覆盖率≥90%（21项中标注≥19项）
- 3分：覆盖率60-89%（13-18项）
- 1分：覆盖率<60%（<13项）

**差异化亮点（15%）**：
- 5分：有2处以上创新且合理的亮点（情境+游戏+评价等组合），与其他项目有明显差异
- 3分：有1处创新设计（如独特的情境创设、创新的游戏设计、特色的评价方式）
- 1分：无亮点，与其他项目试讲稿高度同质化

**可操作性（15%）**：
- 5分：拿来即可直接照念（逐字逐句完整、口令可直接念、逻辑连贯无断裂）
- 3分：需少量调整可用（个别表述需修改、部分环节需补充）
- 1分：考生无法直接使用（占位符多、逻辑断裂、口令不完整）

### 4.3 评估流程

1. **评估输入收集**：每个子技术的4项交付物
2. **逐子技术评分**：以试讲稿为主、其余3项为佐证，按6维度逐项打分（1/3/5分）
3. **加权计算总分**：总分 = Σ（各维度分值 × 权重），满分5分
4. **生成横评报告**：排名表+详细评语+Top3亮点+P1/P2问题清单

### 4.4 评估Agent分组策略

- 按子技术数量均分为2组，启动2个并行评估Agent
- 每个Agent负责一半子技术的逐套评分
- 汇总后生成横评总报告

### 4.5 横评总报告格式

文件名：`横评总报告_{项目编号}{项目名}_{子技术数}套汇总_v1.0.md`

报告结构：
1. 逐套评分总表（含6维度子分+总分）
2. 每套详细评语
3. 项目特殊评估要点核查（如适用）
4. 六维度交叉分析（各维度满分率分析）
5. P1/P2问题清单
6. 汇总统计（平均分、满分套数、通过率、返工数）
7. 按类别表现分析（不同技术类别的平均分和特点）
8. 跨项目对比（与已完成项目的数据对比）
9. 横评总结（整体质量、分层表现、Top3亮点、核心问题）

### 4.6 返工触发规则

满足以下任一条件即触发返工：

| 条件 | 说明 |
|------|------|
| 加权总分 < 3.5分 | 整体质量不达标 |
| 任一维度评分为1分 | 存在严重缺陷 |
| 评分锚点覆盖率 < 60% | 锚点覆盖严重不足 |

优先级判定：
- 高：加权总分<3.0分，或安全组织维度为1分（安全隐患）
- 中：加权总分3.0-3.4分，或口令规范性/锚点覆盖率为1分
- 低：单项维度为1分但总分≥3.5分

### 4.7 评估Agent指令模板

```
【评估指令】
项目：{项目名}
评估范围：{子技术编号列表}

任务：对每个子技术的试讲稿按6维度逐项打分（1/3/5分），加权计算总分。

评估维度与权重：
1. 教学设计合理性(20%)：四环节齐全、时长1+2+6+1、3层递进练习+1比赛、分层练习体现区别对待
2. 口令规范性(15%)：[口令]标记、可直接念出、有预备信号、队形调动标准
3. 安全组织(20%)：无安全隐患、保护帮助规范、组织紧凑
4. 评分锚点覆盖率(15%)：21项中标注≥19项为5分，13-18项为3分，<13项为1分
5. 差异化亮点(15%)：≥2处创新且合理亮点为5分，1处为3分，无亮点为1分
6. 可操作性(15%)：拿来即可直接照念为5分，需少量调整为3分，无法使用为1分

返工触发条件：总分<3.5、或任一维度1分、或锚点覆盖率<60%

输出格式：
- 逐套评分表（6维度子分+总分）
- 每套详细评语（亮点+不足）
- P1/P2问题清单
```

## Phase 5: 问题修复

### 5.1 问题分级

| 级别 | 定义 | 处理方式 |
|------|------|---------|
| P1 | 必须修复，影响使用（如标题与教材术语不一致、缺少核心知识框架、结构性缺失） | 立即修复，修复后重新评估 |
| P2 | 建议修复，不影响使用（如三维素养缺维度、信号不统一、亮点不足、模板同质化） | 修复后更新报告，无需重新评估 |

### 5.2 常见P1问题

- 标题与教材术语不一致
- 缺少核心知识框架（如健康课程缺少"有效沟通四要素"）
- 结构性缺失（如缺少四环节中的某一环节）
- 安全隐患（如体操缺少保护帮助、投掷未统一方向）

### 5.3 常见P2问题

- 三维素养小结缺少某一维度的显性表述
- 游戏起始信号不统一（应统一为"[口令]预备——开始！"）
- 差异化亮点不足（仅1处，需≥2处）
- 模板同质化（多个子技术热身游戏格式一致）
- 子环节时长合计与标注不符（如基本部分子环节合计5.5分钟而非6分钟）
- 自检表自报锚点数与实际标注数不符
- 热身游戏使用了与本课技术不同的动作（引起认知混淆）

### 5.4 修复流程

1. 汇总P1/P2问题清单
2. 逐项修复，覆盖原文件
3. 更新进度文件中对应子技术的状态和得分
4. 更新横评总报告中的P1/P2问题状态
5. P1修复后需重新评估确认通过

## Phase 6: 备考讲义生成

### 6.1 适用场景

当所有项目（或指定项目集）完成横评并通过后，将全部子技术的教学设计要点和试讲稿正文整合为一份可打印的 Word 备考讲义，供考生直接用于试讲备考。

### 6.2 前置条件

- 至少1个项目已完成横评且通过率100%
- 工作目录下存在 `{项目编号}{项目名}/` 目录，内含 `_教学设计_v1.0.md` 和 `_试讲稿_v1.0.md` 文件
- Python 环境已安装 python-docx 库（`pip install python-docx`）

### 6.3 讲义结构

讲义按以下顺序组织内容：

| 部分 | 内容 | 说明 |
|------|------|------|
| 封面 | 标题、副标题、版本号、日期 | 居中大字排版 |
| 使用说明 | 讲义结构说明、备考建议、时间约束、字数范围、导航方式 | 前置内容，不纳入TOC |
| 通用评分标准 | 六维度评分表、评分锚点说明 | 前置内容，不纳入TOC |
| 目录 | Word自动目录域（TOC 1-2级） | 需在Word中右键"更新域" |
| 项目章节 | 每个项目独立分节，页眉显示项目名 | 一级标题 |
| 子技术章节 | 每个子技术独立分页 | 二级标题 |

每个子技术章节包含三部分内容（按序）：

1. **设计要点卡片**（蓝色信息框表格）：从教学设计中提取教学目标、教学重点、教学难点、场地器材，以2列表格呈现（左列标签2.5cm，右列内容13.5cm）
2. **试讲稿正文**：完整试讲内容，含标题层级、口令标注（`[口令]`加粗显示）、交互动作标注、表格
3. **评分检查清单**：汇总该子技术所有评分锚点，以2列表格呈现（左列评分项3.5cm，右列得分动作12.5cm）

### 6.4 格式规范

| 项目 | 规格 |
|------|------|
| 正文字体 | 微软雅黑 10.5pt |
| 行间距 | 1.25倍 |
| 页边距 | 上下左右各2.5cm |
| 信息框背景色 | #DAEEF3（浅蓝） |
| 表头背景色 | #D6E4F0（淡蓝灰） |
| 一级标题 | 18pt 深蓝(#1F497D) |
| 二级标题 | 14pt 蓝(#2E74B5) |
| 三级标题 | 12pt 浅蓝(#4F81BD) |
| 四级标题 | 11pt 灰(#666666) |
| 页眉 | 9pt 灰色，显示当前项目名 |
| 页脚 | 居中页码 |

### 6.5 表格列宽算法

讲义中表格采用**固定布局(fixed layout)** + **内容感知列宽**策略：

1. 遍历表格所有行，计算每列最大视觉长度（中文算2，英文算1）
2. 每列最小宽度 = `min(最大视觉长度/2, 8) × 0.375cm + 0.5cm`（确保4字标签单行显示，长内容不过度分配）
3. 最小宽度之和不超总宽(16cm)时，剩余空间按内容长度比例分配
4. 超出总宽时，优先缩减最宽列，保护短列

关键参数：
- `CHAR_W = 0.375`（cm/中文字）
- `PADDING = 0.5`（单元格内边距）
- `FIT_CAP = 8`（超过8字的内容不再增加列宽，让其自然换行）
- `TOTAL_WIDTH_CM = 16.0`（A4纸减去左右页边距）

### 6.6 生成脚本

讲义生成脚本保存为 `./generate_lecture.py`（与本 SKILL.md 同目录），使用时需修改脚本顶部的 `BASE_DIR` 和 `OUTPUT_PATH` 配置。

脚本核心流程：

```
1. 初始化Document，设置全局样式和页边距
2. 生成封面 → 使用说明 → 通用评分标准 → 目录
3. 遍历项目列表（01~10）：
   a. 创建新分节，设置页眉页脚
   b. 添加项目一级标题
   c. 遍历子技术：
      - 分页 + 二级标题
      - 解析教学设计 → 设计要点卡片
      - 解析试讲稿 → 正文（含口令加粗、表格、标题层级）
      - 汇总评分锚点 → 评分检查清单
4. 保存.docx文件
```

### 6.7 执行步骤

1. 确认所有目标项目的试讲稿和教学设计文件已就位
2. 修改脚本中 `PROJECTS` 列表（如仅需部分项目）
3. 修改 `BASE_DIR` 为实际人教版目录路径
4. 修改 `OUTPUT_PATH` 为输出文件路径
5. 运行 `python generate_lecture.py`
6. 用Word打开生成的文件，右键目录处选择"更新域"生成目录
7. 检查表格列宽、口令加粗、分页是否正常

### 6.8 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 表格列宽不均匀 | 自动布局覆盖了固定布局 | 脚本已强制 `tblLayout type="fixed"`，并在每个cell上设置宽度 |
| 4字标签换行 | 列宽不足 | `compute_col_widths` 中 `FIT_CAP=8` 确保短列最小宽度够4字单行 |
| 目录不显示内容 | Word域未更新 | 打开文档后右键目录区域 → "更新域" → "更新整个目录" |
| 页眉显示错误 | 分节未断开链接 | 脚本对每个新分节设置 `is_linked_to_previous = False` |
| 口令未加粗 | 解析逻辑遗漏 | `add_paragraph_with_commands` 函数对 `[口令]` 标记单独加粗 |

`{教材版本}体育试讲备考讲义_v{版本}.docx`

示例：`人教版体育试讲备考讲义_v1.0.docx`

## 质量基准

基于已完成10个项目432份交付物的横评数据，建立以下质量基准：

| 指标 | 基准值 | 说明 |
|------|--------|------|
| 通过率 | 100% | 所有子技术总分≥3.5且无维度为1分 |
| 平均分 | ≥4.80 | 10个项目平均分范围4.81-4.975 |
| 返工数 | 0 | 不应出现需返工的质量问题 |
| 基础维度满分率 | ≥95% | 教学设计、口令规范、安全组织、锚点覆盖、可操作性5个维度 |
| 差异化亮点满分率 | ≥40% | 这是最容易失分的维度，需重点设计 |

常见失分点及预防措施：

| 失分维度 | 常见原因 | 预防措施 |
|---------|---------|---------|
| 差异化亮点 | 热身游戏格式同质化、分层标准相同 | 每个子技术的热身游戏须贴合技术特点，分层维度须与技术特性关联 |
| 安全组织 | 未明确器材检查口令 | 体操/高器械项目须有器材稳定性检查口令 |
| 口令规范 | 缺少预备信号 | 所有练习口令统一为"预备——XX"格式 |
