# 体育试讲稿生成器

## 定位

基于人教版《体育与健康》教材（或其他版本）生成体育试讲稿项目的完整流水线：初始化 → 子技术识别 → 并行生产 → 六维度横评 → 问题修复 → 备考讲义。每个子技术产出 4 份交付物（教学设计 / 试讲稿 / 队形图 / 自检表）。

## 前置条件

- 用户提供教材文件（MD 格式，放在工作目录或 attachments）。
- 工作目录下存在约束文件（首次由本 skill 指导创建）：`共性约束_v1.0.md`（结构/格式/评分锚点/禁忌）、`横评Agent设计_v1.0.md`（评估维度/流程/返工）、`产品内容大纲_v1.0.md`（全项目子技术清单）。

## 工作流程总览

```
Phase 1 项目初始化 → Phase 2 子技术识别 → Phase 3 并行生产 → Phase 4 六维度横评 → Phase 5 问题修复 → Phase 6 备考讲义
```
每个 Phase 完成后更新进度文件，支持断点续跑。

---

## Phase 1 项目初始化

1. 创建项目目录 `{项目编号}{项目名}`（如 `11健美操`）。
2. 创建进度文件 `进度_{项目编号}_{项目名}.md`，含：项目概况表（子技术总数/交付物总数/通过率/状态）、子技术清单与进度表、教材来源、子技术筛选说明、项目特殊注意事项、横评结果摘要。
3. 在 `产品内容大纲_v1.0.md` 追加新项目信息，更新总览统计（运动大类/子技术总数/交付物总数）。

## Phase 2 子技术识别

1. 读教材 MD，按章节结构梳理技术体系，对照难度水平（水平二★★ / 水平三★★★ / 水平四★★★★）。
2. 筛选原则：
   - **纳入**：教材明确列出的运动技术、10 分钟可完整呈现、有独立教学价值（非辅助动作）。
   - **排除**：纯理论/安全保护方法/战术配合；过基础内容（握拍、站位）；试讲难呈现（需专业器材或对抗）；套路动作过多。
3. 每个子技术定 5 属性：编号 `{项目编号}-{两位序号}` / 名称（教材标准术语）/ 类别 / 难度水平 / 教材定位。

> 🔴 CHECKPOINT — 子技术清单确认：进入并行生产前，确认清单覆盖教材全部技术点，且排除项已按标准剔除。

## Phase 3 并行生产

### 3.1 分组策略
每个生产 Agent 负责 3-6 个子技术（12-24 份交付物），按技术类别分组，启动 2 个并行 Agent。

### 3.2 每子技术 4 份交付物

| 交付物 | 文件名格式 | 内容要求 |
|---|---|---|
| 教学设计 | `{编号}_{项目}_{子技术编号}_{名称}_教学设计_v1.0.md` | 教学目标、重难点、负荷预估、流程概要 |
| 试讲稿 | `..._试讲稿_v1.0.md` | 逐字逐句，含口令、交互标注、评分锚点 |
| 队形图 | `..._队形图_v1.0.md` | 各环节队形布局、调动路线、站位图 |
| 自检表 | `..._自检表_v1.0.md` | 21 项评分锚点逐项自检、字数、时长核对 |

### 3.3 试讲稿结构约束（硬性）

**四环节时长刚性约束**：

| 环节 | 时长 | 字数 | 核心任务 |
|---|---|---|---|
| 开始部分 | 1 分钟 | 180-220 字 | 6 个固定动作 |
| 准备部分 | 2 分钟 | 360-440 字 | 热身游戏 + 自编热身操 |
| 基本部分 | 6 分钟 | 1080-1320 字 | 观察探究→示范讲解→3 层练习→展示比赛 |
| 结束部分 | 1 分钟 | 180-220 字 | 3 个固定动作 |
| 合计 | 10 分钟 | 1800-2200 字 | — |

**开始部分 6 个固定动作**（按序）：集合整队（口令洪亮）→ 考勤报告（与体委互动）→ 师生问好（鞠躬教态）→ 检查服装（尖锐物品/着装）→ 安排见习生 → 宣布内容（情境导入引出课题，不用"今天我们学 XX"）。

**准备部分两类**：一般性准备（约 1 分钟，热身游戏，需有信号反应或方向变化）+ 专项准备（约 1 分钟，自编热身操 4×8 拍，融入主教材关节活动）。

**基本部分「学练赛评」完整链条**：

| 子环节 | 时长 | 必须包含 |
|---|---|---|
| 观察探究 | 1 分钟 | 挂图引导 + 2 观察问题 + 小组讨论 + 自主尝试 |
| 示范讲解 | 1 分钟 | 动作要点（≥3 点）+ 口诀（4-8 字）+ 示范面（正/侧/背）+ 站位 |
| 组织练习 | 3 分钟 | 3 层递进：固定条件单动作 → 变条件附纠错表 → 按水平分层（各组难度不同）+ 每层安全提示 |
| 展示比赛 | 1 分钟 | 比赛名称 + 活动方法 + 评价方式 |

**结束部分 3 个固定动作**：放松活动（针对性，与主教材负荷互补）→ 课堂小结（三维素养显性化：运动能力/健康行为/体育品德）→ 回收器材、下课。

### 3.4 格式约束

- **元信息块**（每文件头部）：`项目: {项目名}　项目编号: {编号}　产物类型: {类型}　版本: v1.0　约束版本: v1.0　生成时间: YYYY-MM-DD HH:MM`
- **口令标注** `[口令]...`：可直接念出、无占位符、有预备信号（"预备——开始"）、队形调动有标准口令（基准+方向+距离）。
- **评分锚点** `> 评分锚点：[项] - [动作]`：21 项中标注 ≥19 项（覆盖率 ≥90%）。
- **交互动作**：用（）标注预期学生反应或教师动作。
- **标题层级**：`## 环节名` → `### 子环节`（时间戳可作环节标题后括注，不作主标题）。
- **术语规范**：符合人教版教材表述，不口语化篡改。

### 3.5 评分锚点清单（21 项，按环节归组）

| 环节 | 锚点 |
|---|---|
| 开始部分 | 教学组织（集合口令洪亮/队列整齐/6 动作完整）、安全管理（检查服装/见习生）、教态仪表（问好鞠躬/精神/着装）、语言表达（情境导入） |
| 准备部分 | 教学组织（热身游戏规则/队形调动）、运动负荷（专项操 4×8 拍完整）、安全管理（热身安全提示）、教法运用（热身游戏设计感/趣味性） |
| 基本部分 | 讲解能力（要点准确/口诀化）、示范能力（示范面正确/站位合理）、教法运用（递进 ≥3 层/学练赛评完整）、教学组织（分组紧凑/队形简洁）、运动负荷（练习密度 ≥50%/运动密度 ≥75%/心率 140-160）、错误纠正（集体+个别纠错/纠错表）、安全管理（保护帮助/器材检查/安全提示）、教学设计（情境合理/区别对待） |
| 结束部分 | 运动负荷（放松互补）、综合素质（三维素养小结）、教学组织（回收器材/下课口令） |

（基本部分安全管理可在多个练习环节分别标注，合计 21 项。）

### 3.6 禁忌清单（反例黑名单）

| 类别 | 编号 | 禁忌内容 |
|---|---|---|
| 技术内容 | T1-T3 | 超教材动作 / 术语口语化篡改（"投篮"→"扔球"）/ 技术要点知识性错误 |
| 安全组织 | S1-S4 | 安全隐患组织（相向投掷/无保护高器械）/ 体操无保护帮助 / 投掷未统一方向口令 / 高器械无保护垫 |
| 口令 | C1-C4 | 模糊口令 / 占位符（`[口令]XXX`）/ 缺预备信号 / 队形调动无口令 |
| 教学表达 | E1-E5 | 通用套话 / 无负荷数据 / 无核心素养 / 碎片化教学 / 无区别对待 |
| 格式 | F1-F5 | 字数超 1800-2200 / 时长≠10 分钟 / 缺环节 / 缺元信息块 / 锚点覆盖率 <90% |

### 3.7 健康课程特殊约束

健康课程不涉及运动技能，核心是综艺式互动游戏。基本部分改为：游戏导入（1-1.5 分钟，引出主题）→ 游戏探究（2 分钟，闯关/分类/抢答，≥3 知识要点）→ 游戏拓展（1.5-2 分钟，迁移生活场景）→ 总结评价（1 分钟，知识回顾+习惯建议）。至少 2 个游戏环节，每个承载明确知识点；准备部分用健康知识抢答替代身体热身；三维素养改为健康知识/健康行为/健康品德。

### 3.8 生产 Agent 指令模板

```
【生产指令】
项目：{项目名}　负责子技术：{编号列表}　教材来源：{路径}　约束文件：共性约束_v1.0.md
任务：为每个子技术产出 4 份交付物，保存至 {项目目录}。
硬性约束：① 试讲稿 1800-2200 字，四环节 1+2+6+1=10 分钟；② 开始 6 固定动作、基本部分学练赛评、结束 3 固定动作；③ 口令加 [口令] 标记可直念无占位符；④ 评分锚点覆盖率 ≥90%；⑤ 第三层练习按水平分组不同要求；⑥ 术语符合人教版。
完成后更新进度文件对应子技术状态为"完成"。
```

## Phase 4 六维度横评

### 4.1 评估维度表

| 维度 | 权重 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|---|
| 教学设计合理性 | 20% | 环节缺失/时长失衡 | 完整但缺层次 | 完整且层次递进 |
| 口令规范性 | 15% | 多处模糊口令 | 基本清晰欠精炼 | 准确精炼可直念 |
| 安全组织 | 20% | 有安全隐患 | 安全但组织松散 | 安全且紧凑高效 |
| 评分锚点覆盖率 | 15% | <60%（<13 项） | 60-89%（13-18 项） | ≥90%（≥19 项） |
| 差异化亮点 | 15% | 无亮点 | 1 处亮点 | ≥2 处创新合理亮点 |
| 可操作性 | 15% | 无法直接使用 | 需少量调整 | 拿来即可照念 |

### 4.2 评估流程与报告

1. 逐子技术评分（试讲稿为主、其余 3 项佐证），按 6 维度 1/3/5 打分。
2. 加权总分 = Σ(维度分 × 权重)，满分 5 分。
3. 生成横评总报告 `横评总报告_{项目编号}{项目名}_{子技术数}套汇总_v1.0.md`：逐套评分总表、每套评语、项目特殊要点核查、六维度交叉分析、P1/P2 清单、汇总统计、按类别表现、跨项目对比、横评总结（Top3 亮点 + 核心问题）。

### 4.3 返工触发规则

| 条件 | 说明 | 优先级 |
|---|---|---|
| 加权总分 < 3.5 | 整体不达标 | 中 |
| 任一维度 1 分 | 严重缺陷 | 高（安全组织 1 分） |
| 锚点覆盖率 < 60% | 覆盖严重不足 | 中 |

> 🔴 CHECKPOINT — 横评结果确认：进入修复前，确认横评总报告已生成、P1/P2 已分级、返工范围已明确。

## Phase 5 问题修复

| 级别 | 定义 | 处理 |
|---|---|---|
| P1 | 必须修复，影响使用（标题术语不一致 / 缺核心知识框架 / 结构性缺失 / 安全隐患） | 立即修 + 重新评估 |
| P2 | 建议修复（三维素养缺维度 / 信号不统一 / 亮点不足 / 模板同质化 / 时长不符 / 自检表锚点数不符） | 修后更新报告，无需重评 |

修复流程：汇总 P1/P2 清单 → 逐项修覆盖原文件 → 更新进度文件状态与得分 → 更新横评报告问题状态 → P1 修复后重新评估确认通过。

## Phase 6 备考讲义生成

所有项目横评通过后，将全部子技术的教学设计要点 + 试讲稿正文整合为可打印 Word 讲义。

- **结构**：封面 → 使用说明 → 通用评分标准 → 目录（Word 自动目录域）→ 项目章节（独立分节，页眉显示项目名）→ 子技术章节（独立分页）。每个子技术含：设计要点卡片（蓝框 2 列表格）+ 试讲稿正文（口令 `[口令]` 加粗）+ 评分检查清单（2 列表格）。
- **脚本**：`generate_lecture.py`（与 SKILL.md 同目录），改顶部 `BASE_DIR`/`OUTPUT_PATH`/`PROJECTS` 后运行；Word 中右键目录"更新域"。
- **命名**：`{教材版本}体育试讲备考讲义_v{版本}.docx`，如 `人教版体育试讲备考讲义_v1.0.docx`。

## 项目特殊注意事项模板

每个新项目在进度文件「特殊注意事项」明确 6 维度：安全间距（如武术 2 米）、文化融入（如武术抱拳礼+武德）、术语规范（标准 vs 错误表述对照）、器材需求、示范面（手型/步型用正+侧、手法/腿法用侧+背、套路用背领做+正展示）、保护帮助（体操器械类）。

## 失败恢复

| 触发条件 | 一线处理 | 仍失败时的兜底 |
|---|---|---|
| 教材缺失或格式非 MD | 🔴 STOP，报告缺失 | 请用户提供教材或切已有项目 |
| 约束文件缺失 | 🔴 STOP，先指导创建 | 请用户确认是否沿用既有版本 |
| 子技术清单定位不唯一或超教材范围 | 🔴 STOP，列候选不擅自筛选 | 请用户改选或确认筛选标准 |
| 交付物字数/结构/口令校验失败 | 按禁忌清单 F1-F5 逐项修再重跑 | 不改约束阈值、不删字段、不用外部常识补教材没有的事实 |
| 横评触发返工 | 按 P1/P2 分级逐项修 | P1 重评、P2 更新报告 |
| 讲义脚本表格列宽/口令加粗/分节异常 | 按脚本「常见问题」排查 | 不修改源教材与约束文件 |

## 质量基准

基于 10 个项目 432 份交付物的横评数据：通过率 100%（总分 ≥3.5 且无维度 1 分）、平均分 ≥4.80、返工数 0、基础维度（教学设计/口令/安全/锚点/可操作）满分率 ≥95%、差异化亮点满分率 ≥40%（最易失分维度，需重点设计）。常见失分：热身游戏同质化、未明确器材检查口令、练习口令缺预备信号——每个子技术的热身游戏须贴合技术特点，分层维度须与技术特性关联。
