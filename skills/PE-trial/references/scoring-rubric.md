# 评分矩阵 R1（稳定唯一 ID）

> 版本：R1（2026-08-17）。ID 一经发布即冻结：只能新增维度/锚点（R2），不得复用旧 ID 表达新含义。
> 用途：**独立评审专用**。生产者（写稿的 worker）不得用本矩阵给自己打分（消灭自证评分）；评审逐项给出"文件+行号+教材证据"。

## 0. 铁律

1. **VETO-SAFETY 与 VETO-KNOW 为一票否决**：任一命中 -> 整份产物不合格，直接打回，其他维度不再计分。
2. **待演练项 `[LIVE]`**：需真人录像/现场才能判断的子项，文本评审只标 `[LIVE] 待演练`，**禁止**依据文字描述给分。
3. **禁止文本自报满分**：生产者自检表只能给"通过/不通过/待演练"三态 + 证据行号，不得出现"满分/优秀/9分"等自评分。
4. 每个判定必须落到证据：`产物路径:行号` +（教材类）`EXAM_PROFILE.textbook_pages` 页码回溯。无证据 = 不通过。

## 1. 维度与子项（ID 唯一）

### V 一票否决（先查）

| ID | 内容 | 判定 |
|----|------|------|
| `VETO-SAFETY` | 安全红线：高风险动作（跳马/单杠/投掷/跳箱等）无保护帮助措施；器材未检查即使用；队形组织存在相撞/砸伤路径；健康课涉及身体指标/隐私不当处理 | 命中任一即整卷不合格 |
| `VETO-KNOW` | 知识错误：动作技术要领与教材冲突；口令/规则/运动生理常识错误（如拉伸时机、心率区间误用）；课标学段目标错配 | 命中任一即整卷不合格 |

### A 教材与技术准确

| ID | 子项 | 锚点（1 不达标 / 2 合格 / 3 良好） | 判定方式 |
|----|------|-----------------------------------|---------|
| `A1` | 技术要领与教材一致 | 1=与教材页冲突；2=关键要领齐、个别表述含糊；3=要领-重点-难点-易错均与教材页吻合 | 文本+教材页比对 |
| `A2` | 课标学段匹配 | 1=目标超/低于学段；2=基本匹配；3=水平目标+学业要求逐条对应 | 文本+课标比对 |
| `A3` | 术语与口令规范 | 1=术语错误；2=个别口语化；3=专业术语+队列口令全规范 | 文本 |
| `A3a [LIVE]` | 口令实际音量/节奏/哨音效果 | 现场录音录像 | 待演练 |

## 2. 计分与报告

- 文本可判定子项：`通过(=锚点2以上)/不通过/待演练` 三态；评审 JSON 必须含每项 `evidence`（文件:行号）。
- 维度小结 = 该维度子项三态汇总；**不含数值总分**（绝对分只作教研诊断，不进评审结论）。
- `[LIVE]` 子项计入"待演练清单"，交付报告必须附演练验证方法（录像自评清单）。
- 首次通过率 / 修复轮次 / 最终通过率由协调者统计（见 SKILL.md 评审流程）。
