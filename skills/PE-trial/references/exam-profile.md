# EXAM_PROFILE：考试画像配置

> 版本：R1（2026-08-17）。修改评分/画像口径须在 `PROGRESS.md` 记录理由并开 R2。
> 定位：`EXAM_PROFILE` 是**每次任务的输入配置**，不是全国统一标准。10 分钟、1+2+6+1、1800–2200 字仅为有来源的**默认画像/诊断值**，以当地公告为准。

## 1. 权威依据（必须引用）

| 来源 | 用途 | URL |
|------|------|-----|
| 教育部考试中心 教师资格考试面试大纲（NTCE 资料下载-面试大纲） | 教资面试环节构成（备课/试讲/答辩）与测评维度 | https://ntce.neea.edu.cn/html1/category/1511/693-1.htm |
| 教育部《义务教育课程方案和课程标准（2022 年版）》印发通知（教材〔2022〕2号） | 课标依据；内含《义务教育体育与健康课程标准（2022年版）》PDF 直链 | https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html |

以上为**全国性依据**。各省、各地市教师编（教师招聘）考试的时长、环节、技能展示要求**各地不同**，一律只进入画像字段，不得冒充全国标准；无法联网核验的地方规则标"未验证，以当地公告为准"。

## 2. 字段定义（生成前必须逐项确认）

| 字段 | 含义 | 必填 | 默认值（含来源标注） |
|------|------|------|---------------------|
| `exam_type` | 考试类型：`tuhuan`(教师编) / `ntce`(教资面试) / `other` | 是 | `tuhuan`（本 skill 主目标） |
| `region_year` | 地区与年份，如 `广东省某市/2026`；未知填 `unknown` | 是 | `unknown`（未验证，以当地公告为准） |
| `stage_grade` | 学段与年级，如 `小学三年级` | 是 | 无默认，必填 |
| `standard` | 课标版本 | 是 | 《义务教育体育与健康课程标准（2022 年版）》（来源见上表第二行） |
| `textbook_pages` | 教材版本与页码，如 `人教版《体育与健康》某册 P12-13` | 是 | 无默认，必填（净稿技术要领必须能回溯到此页） |
| `deliverable_type` | `full_lesson`(完整课设计) / `interview_segment`(面试片段) | 是 | `full_lesson`；两者区别见 §4 |
| `prep_minutes` | 备课时长（分钟） | 是 | 教资：20（NTCE 面试大纲）；教师编：`null`（未验证，以当地公告为准） |
| `trial_minutes` | 试讲时长（分钟） | 是 | 10（诊断默认值：教资大纲为 10；教师编常见 8–15，**以当地公告为准**） |
| `defense` | 是否含答辩/结构化：`none`/`structured`/`defense` | 是 | `none`（未验证时按无答辩设计，报告标注） |
| `skill_demo` | 是否含技能展示（动作示范考核） | 是 | `false`（未验证时按无，报告标注） |
| `student_mode` | 无生试讲(`no_student`) / 有生(`with_student`) | 是 | `no_student`（面试片段与教师编主流形态） |
| `equipment` | 器材与场地约束清单；`media_allowed` 多媒体可用性 | 是 | `[]` + `media_allowed:false`（按裸考场最保守设计；实际放宽由画像覆盖） |

画像确认失败的失败分支：任一"必填"字段缺失且用户拒绝回答 -> 产出物仅到"备课提纲"，不出净稿，并在报告写明缺哪些字段。

## 3. 默认画像（诊断值，非硬规则）

```yaml
# tuhuan 默认画像（诊断用，region_year=unknown 时生效）
exam_type: tuhuan
trial_minutes: 10          # 来源：NTCE 大纲试讲 10 分钟 + 教师编常见值；非全国规则
segment_split: "1+2+6+1"   # 导入1 + 热身2 + 基本6 + 结束1（分钟）；本 skill 教研诊断默认
word_target: 1800-2200     # 净稿字数诊断区间（≈10 分钟口播量，语速 200–240 字/分钟）；非评分标准
```

- 三个诊断值仅用于**结构与篇幅自查**，不得写进对外说明冒充官方要求。
- NTCE 画像差异：`prep_minutes:20`、`trial_minutes:10`、`defense:defense`（结构化问答+答辩5分钟，以大纲为准）。
- 任何字段被当地公告覆盖时，净稿与自检必须按覆盖值重算（时长求和 = trial_minutes）。

## 4. 完整课设计 vs 面试片段

| 维度 | `full_lesson` 完整课设计 | `interview_segment` 面试片段 |
|------|------------------------|------------------------------|
| 环节 | 开始+热身+基本+结束全环节 | 允许裁剪（常见：热身+基本核心段） |
| 时长 | 按 `trial_minutes` 全程分配 | 按 `trial_minutes` 但环节可少 |
| 文档 | 五件套全出 | 净稿+队形安全图必出，板书可并入净稿 |
| 自检 | 全维度 | 仅覆盖出现过的维度 |

## 5. 地方规则处理纪律

1. 用户提供的地方公告原文 -> 记入画像字段并标注"用户提供，未联网核验"。
2. agent 检索到的地方规则 -> 标注"已检索，URL+日期"，无法核验时降级为"未验证"。
3. 禁止把任何地方规则写为"全国要求/统考要求"。
